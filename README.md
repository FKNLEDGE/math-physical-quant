# 数学物理与量化 · 自学项目

> 一个农学生从零开始，系统自学**数学物理**与**量化（Quant）**的长期项目。
> 站在权威教程的肩膀上，改造成「小白也能走完」的学习路线。

---

## 🎯 这个项目是什么

这不是又一个「量化策略代码仓库」，而是一套 **为零基础学习者设计的、可执行的学习系统**。它的三个特点：

1. **基地 + 分支**：先夯实一个统一的「基地」（数学、编程、金融常识、思维方法），再从基地分出多条学习路线（量化交易 / 衍生品定价 / 组合管理 / 机器学习量化 / 数学物理深化）。
2. **不重复造轮子**：核心知识来自公认的权威教材与课程（见 [资源清单](docs/04-权威资源清单.md)），本项目做的是 **筛选、串联、翻译成小白语言、配可运行的代码**。
3. **不止于「怎么做」，更讲「为什么」**：每个主题都尽量交代它的 **历史从哪来、背后的思维模型是什么、有什么哲学与局限**。知道公式怎么用很容易，知道它为什么长这样、什么时候会失效，才是真本事。

> 作者背景：农学生，有一定数学与物理基础，量化基础为 0。工具选择 **Python（主力）+ 一点 C++（性能关键处）**。

## 🚦 怎么用这个项目

把它当成一本「活的教科书 + 实验记录本」：

1. **读总纲** → 建立全局观，知道自己在地图的哪个位置。
2. **挑一条路线** → 小白建议先走「量化入门」主线，遇到缺的数学再回「基础」补（按需学，别一上来啃三年数学）。
3. **每个主题三件套**：①读笔记理解概念 → ②跑/改代码获得手感 → ③用[费曼技巧](docs/02-方法论与思维模型.md)用自己的话复述一遍。
4. **记录进度**：在下面的进度表里打勾，或用 git commit 当成学习日记。

> 💡 学习心法：**先求会用，再求理解，最后求批判**。先让一个简单策略跑起来获得正反馈，再回头理解每一步的数学，最后追问「它什么时候会骗我」。
