# 物理 🔬

> 你的**优势区**。这里有两条用途：①把数学物理方法学扎实（它和量化共享大量数学）；
> ②理解物理与金融的隐秘联系（econophysics）——这是很多物理人切入量化的天然入口。

## 为什么物理和量化是表亲

| 物理概念 | 金融对应 |
|---|---|
| 热/扩散方程 | 期权定价（Black-Scholes 经换元就是热方程） |
| 随机游走 / 朗之万方程 | 价格过程、几何布朗运动 |
| 统计力学（系综、配分函数） | 大量交易者的集体行为、风险中性测度 |
| 路径积分（费曼） | 衍生品定价的路径积分法 |
| 相变、临界、幂律 | 市场崩盘、厚尾、波动率聚集 |

> 完整脉络见 [哲学与历史背景 · 物理与金融](../../docs/03-哲学与历史背景.md)。

## 学习提示

- 入门别急着啃 econophysics 论文，**先读科普建立图景**：《华尔街物理学》→《宽客人生》。
- 把「热方程 → Black-Scholes」这条换元亲手推一遍，是连接两个世界的最佳练习（放到[量化路线 B](../../docs/01-学习路线图.md)时做）。
