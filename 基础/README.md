# 基础 · 夯实的基地 🏗️

> 这里是所有学习路线共享的地基。**但请记住路线图的核心原则：基地不必一次学满，缺啥补啥（即时学习）。**

## 怎么用这个目录

- 每个支柱下，按主题建子笔记（学到哪记到哪）。
- 每则笔记建议遵循：**人话解释 → 它在量化里干嘛 → 一段可运行的小代码 → 费曼复述**。
- 权威教材与课程见 [docs/04-权威资源清单](../docs/04-权威资源清单.md)，别重复造轮子。
