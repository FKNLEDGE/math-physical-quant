## 学习提示

- 先 **概率统计**，它是量化最核心、也最容易被低估的一块。
- 你的物理背景在「微积分、线代、随机过程」上是优势——更多是补金融语境。
- 每学一个概念，回答：「它在[量化主线](../../量化/)的哪一步会用到？」答不出就说明还太抽象。
