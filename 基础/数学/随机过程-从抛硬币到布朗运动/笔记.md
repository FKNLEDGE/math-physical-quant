# 随机过程 · 从抛硬币到布朗运动

## 一、本质（一句话）

> **随机过程 = 描述「一个随机量如何随时间一步步演化」的数学。**
> 股价、花粉位置、赌徒的钱、分子的运动……凡是「下一刻去哪带有随机性、又一步步累积」的东西，都是它。

**为什么量化离不开它？** 因为市场的本质就是「**随机 + 时间**」。你没法预测明天的价格（随机），但你能描述它**可能去哪、概率多大、不确定性随时间怎么扩散**（过程）。这就是量化能做的全部——不是算命，是给不确定性建模。

## 二、最简单的例子：抛硬币 → 随机游走

把复杂的东西剥到最简单。市场最朴素的模型，就是**喝醉的人走路**（醉汉漫步）：

> 每一步，硬币决定方向：正面 → 向右一步（+1），反面 → 向左一步（−1）。他现在在哪？把每一步加起来。

用符号写：第 $i$ 步是 $X_i \in \{+1, -1\}$（各 50%），走了 $n$ 步后的位置是

$$S_n = X_1 + X_2 + \cdots + X_n$$

这就是**随机游走**——最简单的「股价」模型（把"位置"换成"价格"）。

### 🔑 第一性原理：它会走多远？（亲手推一遍）

别背结论，我们一步步算。问两个问题：**平均在哪？散得多开？**

**平均位置**（期望）：每步期望 $E[X_i] = (+1)(0.5) + (-1)(0.5) = 0$。期望可加，所以
$$E[S_n] = E[X_1] + \cdots + E[X_n] = 0$$
**平均而言他在原地**——因为左右对称。但这不代表他"没走远"，只是"往左往右一样多"。

**散开程度**（方差）：这才是关键。因为每步**相互独立**，方差可加（独立是前提！）：
$$\mathrm{Var}(S_n) = \mathrm{Var}(X_1) + \cdots + \mathrm{Var}(X_n) = n \cdot \mathrm{Var}(X_1)$$
而单步方差 $\mathrm{Var}(X_i) = E[X_i^2] - (E[X_i])^2 = 1 - 0 = 1$。所以
$$\boxed{\mathrm{Var}(S_n) = n, \qquad \text{标准差} = \sqrt{n}}$$

### 这个 √n 是整门学问的灵魂

**方差随时间线性增长，但标准差（典型偏离）只按 $\sqrt{n}$ 增长。** 走 100 步，典型偏离原点约 10 步，而不是 100 步。不确定性会扩散，但**是"开方级"地慢慢扩散**。

> 代码实验①验证了它：3000 条路径走 200 步，终点标准差实测 14.30 ≈ √200 = 14.14。✅

> 🔗 **闭环时刻！** 第 03 课那条"年化波动 = 日波动 × √252"的公式，现在你彻底懂了：一年有 252 个交易日，波动（标准差）随时间按 √天数 增长，所以乘 √252。**它不是约定俗成的换算，是随机游走的基本定律。** 这就是"知其所以然"。

## 三、从离散到连续：布朗运动登场

随机游走是"一步一跳"的（离散）。现在做物理学家最爱做的事：**取极限**。

把步子变得越来越小、越来越密——一秒走一步，变成一毫秒走一步、一微秒走一步……在极限下，这条折线变成一条**连续的曲线**，叫 **布朗运动**（Brownian Motion，也叫维纳过程 $W_t$）。

> 代码实验②画出了这个逼近：步数从 20 → 200 → 4000，折线越来越像一条连绵不断、却又处处毛糙的曲线。

布朗运动 $W_t$ 的三条核心性质（都从随机游走继承而来）：

1. **连续但处处不光滑**：画得出来（连续），却在任何一点都没有切线（不可导）。放大任何一小段，它还是一样毛糙——**自相似 / 分形**。
2. **独立增量**：不重叠的两段时间，走法互不影响（无记忆）。
3. **增量是正态的**：从 $t$ 到 $t+\Delta t$ 的位移 $\Delta W \sim \text{正态}(0,\ \Delta t)$。也就是说，**方差 = 时间间隔**，标准差 = $\sqrt{\Delta t}$——还是那个 √ 定律！

### 🔬 物理与金融的世纪交汇（你的主场）

这条曲线，你在物理里其实见过：

- **1827** 年植物学家布朗，显微镜下看到花粉颗粒在水里乱颤。
- **1905** 年爱因斯坦用它解释**扩散**：花粉被无数水分子从四面八方撞，每次撞击就像一次"抛硬币"，累加起来就是布朗运动。他还由此算出了原子的大小。
- 而**早 5 年**，**1900** 年 Bachelier 在博士论文里，已经用**完全相同的数学**描述巴黎股市的价格波动，给期权定价。

> **同一个 $W_t$，物理学家用来数原子，金融家用来定期权。** 你在《数学物理方法》里和扩散/热传导打过的交道，就是量化定价的底层数学。这不是巧合——**"大量微小随机冲击的累积"这个结构，在自然界和市场里是同一个**。（详见[哲学与历史背景](../../../docs/03-哲学与历史背景.md)）

## 四、为什么股价要用「几何」布朗运动

直接拿布朗运动当股价，有两个硬伤：

1. **会变负**：布朗运动能走到 −50，但股价不会是负的。
2. **涨跌该按比例**：100 块的股票一天动 1 块很正常，1 块的股票一天动 1 块是翻倍。绝对波动不该是常数，**百分比波动**才该是。

怎么修？**让"对数价格"做布朗运动**，而不是价格本身。即价格 = $e^{\text{布朗运动}}$。指数永远为正（解决硬伤1），且对数对应"百分比"（解决硬伤2）。这就是**几何布朗运动（GBM）**：

$$S_t = S_0 \exp\Big( \underbrace{(\mu - \tfrac{1}{2}\sigma^2)\,t}_{\text{趋势}} + \underbrace{\sigma W_t}_{\text{随机波动}} \Big)$$

写成大家更常见的"变化率"形式：

$$\frac{dS}{S} = \underbrace{\mu\, dt}_{\text{漂移：平均趋势}} + \underbrace{\sigma\, dW}_{\text{扩散：随机冲击}}$$

- $\mu$ = 漂移率（平均每年涨多少），$\sigma$ = 波动率（颠簸多大）。
- 第一项是"方向"，第二项是"随机性"。**趋势 + 噪声**，这就是最经典的股价模型。

> 🔗 **闭环时刻！** 这正是第 01 课 `simulate_gbm` 那几行代码：`(mu - 0.5*sigma**2)*dt + sigma*sqrt(dt)*randn`。你当时照着跑，现在你**从第一性原理重新发明了它**。那个神秘的 `- 0.5*sigma**2` 是哪来的？看下一节。

## 五、伊藤引理的灵魂：一个反直觉的 `(dW)² = dt`

这是随机微积分**唯一**真正反直觉、但理解了就豁然开朗的点。慢慢看。

### 普通微积分为什么在这失效

普通微积分里，一个微小变化 $dx$ 的平方 $(dx)^2$ 是"高阶无穷小"，小到可以直接扔掉。

但布朗运动不一样：一小步 $\Delta W$ 的**大小**是 $\sqrt{\Delta t}$（因为标准差 = √时间）。那么它的**平方** $(\Delta W)^2$ 的大小就是 $\Delta t$——**和 $\Delta t$ 同一量级，不能扔！**

$$(\Delta W)^2 \approx \Delta t \quad(\text{而不是} \approx 0)$$

### 亲眼看见它

代码实验③把每一小步的 $(\Delta W)^2$ 累加起来：

> 结果 = 1.067 ≈ 总时间 T = 1.0。**不是 0！** 而同样这些步子，$\Delta W$ 本身累加（就是 $W_t$）却在 0 附近乱晃。

也就是说：**$W_t$ 本身充满随机（不可预测），但它的"波动量平方"的累积却是确定的、等于流逝的时间。** 这个量叫"二次变差"，是布朗运动的指纹。

### 伊藤引理 = 泰勒展开，但多留一项

于是，对随机量做"换元/复合函数求导"时，泰勒展开的二阶项 $\frac{1}{2}f''(dW)^2 = \frac{1}{2}f'' dt$ **必须保留**。这就是**伊藤引理**：

$$dY = f'(W)\,dW + \tfrac{1}{2}f''(W)\,dt$$

比普通链式法则**多出一个 $\frac{1}{2}f'' dt$ 项**。整个随机微积分、整个 Black-Scholes，都建立在这一项上。

### 那个 −½σ² 的真面目：波动率拖累

把伊藤引理用在"价格 → 对数价格"上，那多出来的项正好是 $-\frac{1}{2}\sigma^2$。它有个极接地气的含义——**波动率拖累**：

> **涨 10% 再跌 10%，回不到原点**：$1 \times 1.1 \times 0.9 = 0.99$，亏了 1% ≈ $\frac{1}{2}(0.1)^2$。
> 波动本身就在啃食复利。波动越大（σ 越大），拖累越狠。

代码实验④用 2 万条 GBM 印证：哪怕设趋势 $\mu = 0$，因为 $-\frac{1}{2}\sigma^2$，价格中位数也会**往下漂**（实测中位数 0.92 < 1）。

> 🔗 **三重闭环！** 这一个 $-\frac{1}{2}\sigma^2$，同时解释了：① 第 01 课代码里那行神秘的 `mu - 0.5*sigma**2`；② 第 03 课"+10% 再 −10% 不回本"的不对称；③ [方法论文档](../../../docs/02-方法论与思维模型.md)里讲的"复利的凸性"。**一个数学事实，三处现象，全打通了。**

## 六、思维模型（可迁移到别处的思考方式）

1. **随机但有结构**：你**预测不了具体路径**（明天涨跌），但**预测得了分布**（一年后价格的可能范围与概率）。量化放弃"算命单点"，转而"管理分布"——这是世界观的转变。
2. **√t 法则（次线性扩散）**：不确定性随时间增长，但**按开方慢慢长**，不是线性爆炸。许多"时间换确定性"的直觉（长期投资为何更稳）根子在这。
3. **凸性 / 詹森不等式**：$E[f(X)] \ne f(E[X])$。波动率拖累、期权的不对称收益、[Taleb 的反脆弱](../../../docs/03-哲学与历史背景.md)，本质都是"曲线弯不弯"。$f$ 凸则波动有利，凹则波动有害。
4. **路径 vs 分布（遍历性预告）**：一群人各赌一次的平均（系综平均），不等于一个人连赌很多次的结果（时间平均）。波动率拖累就是个例子——平均收益为正，单条路径却可能一路下行。这是风险管理最深的洞见之一。

## 七、哲学指导与局限：布朗运动是金融的「氢原子」

物理里，氢原子是最简单、能精确求解、又抓住了量子本质的模型——但真实原子复杂得多。**布朗运动之于金融，正是氢原子之于物理**：

- 它是最简单、能算到底、抓住了"随机+趋势"本质的模型，是一切的**基准**。
- 但真实市场**不完全是**布朗运动：
  - **厚尾**：增量不是正态，极端暴涨暴跌远比正态多（2008、闪崩）。
  - **波动聚集**：增量不独立，大波动扎堆出现（我们的[示例数据](../../../量化/数据/)就特意加了这个）。
  - **跳跃**：价格会瞬间跳空，不总是连续的。

> Mandelbrot 一生都在批判"正态金融"低估了灾难。**所以正确的态度是**：用布朗运动建立直觉和基准，**同时清醒地知道它在尾部会骗你**。模型是地图，不是疆域（[Box：所有模型都是错的，但有些有用](../../../docs/02-方法论与思维模型.md)）。**2008 年的教训，本质就是太多人忘了这条。**

## 八、方法论：你刚刚用的，正是物理学家的办法

回看这一课的路径：**抛硬币（最简具体）→ 推期望方差（第一性原理）→ 取极限（布朗运动）→ 模拟验证（动手）→ 连接已知（闭环）→ 反思局限（批判）。**

这套"**从最简单的特例出发，模拟先行、再上严格证明，最后批判其边界**"的打法，就是物理学家征服未知的标准流程，也是本项目反复强调的[方法论](../../../docs/02-方法论与思维模型.md)。**你有物理训练，这是你的天然优势——把它用在量化上。**

## 十、本课小结（费曼版）

- **随机过程**：描述随机量如何随时间演化。最简模型 = **抛硬币累加的随机游走**。
- **√n 定律**：方差随时间线性增长，标准差按 √n —— 这就是 √252 的根源。
- **布朗运动**：随机游走取极限的连续版；连续却处处不光滑（分形）；**爱因斯坦的花粉 = Bachelier 的股价，同一个数学**。
- **几何布朗运动**：让对数价格做布朗运动，得到第 01 课的股价模型 `趋势 + 噪声`。
- **伊藤的灵魂**：$(dW)^2 = dt$ 不可忽略 → 随机微积分多一项 → 冒出 $-\frac{1}{2}\sigma^2$ 的**波动率拖累**。
- **态度**：布朗运动是金融的"氢原子"——抓住本质的基准，但**真实市场有厚尾、聚集、跳跃，别在尾部信它**。
