# 线性代数 · 组合与协方差的几何

> 一句话动机：单只股票的分析靠概率统计就够了；**一旦你要同时持有一篮子资产**，就必须用线性代数。
> 它把"分散投资"这句老话，变成可计算的几何。配套代码：[`linear_algebra_portfolio.py`](linear_algebra_portfolio.py)。

> 🧭 按[「讲透」模板](../../../docs/06-深入学习大纲.md)：本质 → 最简例子 → 推导 → 思维模型 → 哲学 → 闭环。

---

## 一、本质（一句话）

> **线性代数 = 「一次处理很多个数」的数学。** 向量是"一串有含义的数"（比如一个组合里各资产的权重）；矩阵是"一张关系表 / 一个变换"（比如资产间两两怎么联动）。

**为什么量化离不开它？** 真实投资从不是只买一只股票，而是配置**一篮子**（几十上百个标的）。线性代数让你把"一篮子"当成**一个对象（向量）**来运算，而不是一个个手算。而其中最重要的矩阵——**协方差矩阵**——就是**风险的结构**本身。

---

## 二、最简单的例子：两个资产的组合

把一切剥到最简单：你只有两只股票 A 和 B，钱怎么分？

用一个**权重向量**表示：$\mathbf{w} = (w_A, w_B)$，且 $w_A + w_B = 1$（钱分完）。比如 60% 买 A、40% 买 B 就是 $(0.6, 0.4)$。

**组合的收益** = 各资产收益按权重加权。如果某天 A 涨 $r_A$、B 涨 $r_B$，组合涨：
$$r_p = w_A r_A + w_B r_B = \mathbf{w} \cdot \mathbf{r}$$

这个"加权求和"就是**点积（dot product）**——线性代数的第一块积木。你已经在第 04 课的回测里用过它（`持仓 × 收益`），只是当时没点破。

> 💡 第一个观念升级：**组合 = 向量**。一篮子资产的权重是一个向量，收益是另一个向量，组合收益是它们的点积。资产从 2 个变成 500 个，公式**一模一样**（$\mathbf{w}\cdot\mathbf{r}$），这就是向量记号的威力——抓住本质，无视数量。

## 三、风险的结构：协方差矩阵

收益好算（点积），**风险**才是难点，也是线性代数大显身手的地方。

### 先回顾两个概念（从第03课来）
- **方差/波动率**：单个资产自己抖得多厉害（$\sigma_A^2$）。
- **协方差**：两个资产**一起**抖的倾向。$\text{Cov}(A,B) = E[(r_A - \bar r_A)(r_B - \bar r_B)]$。
  - 同涨同跌 → 协方差为正；一涨一跌 → 为负；毫无关系 → 约 0。
- **相关系数**：把协方差归一化到 $[-1, 1]$，$\rho = \dfrac{\text{Cov}(A,B)}{\sigma_A \sigma_B}$。+1 完全同步，−1 完全反向，0 无关。

### 把它们装进一个矩阵
多个资产时，把"谁和谁怎么联动"全部装进**协方差矩阵 Σ**：
$$\Sigma = \begin{pmatrix} \sigma_A^2 & \text{Cov}(A,B) \\ \text{Cov}(A,B) & \sigma_B^2 \end{pmatrix}$$
对角线是各自的方差，非对角线是两两协方差。**这个矩阵，就是整个投资组合的"风险地图"。**

### 🔑 组合方差 = wᵀΣw（亲手推一遍）

组合的风险有多大？我们要 $\text{Var}(r_p) = \text{Var}(w_A r_A + w_B r_B)$。用方差的展开规则一步步来：
$$\text{Var}(r_p) = w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 + 2 w_A w_B \,\text{Cov}(A,B)$$

这一长串，用矩阵写出来就是优雅的一句：
$$\boxed{\sigma_p^2 = \mathbf{w}^\top \Sigma\, \mathbf{w}}$$

> 代码里 `text_demo_covariance` 直接算了 `w @ Σ @ w`，你可以对照展开式验证它俩相等。**记住这个 $\mathbf{w}^\top\Sigma\mathbf{w}$**——它是整个现代组合理论（路线 C）的核心公式，也是一个"二次型"（几何上对应椭圆，后面优化会用到）。

## 四、分散投资：唯一的「免费午餐」🍱

现在见证线性代数最美的一个结论。看上面方差展开式的**最后一项** $2 w_A w_B \,\text{Cov}(A,B)$——关键全在这里。

假设 A、B 波动率都是 20%，各买一半。组合波动随相关性 $\rho$ 怎么变（代码实验①）：

| 相关性 ρ | 组合波动 | 含义 |
|---|---|---|
| **+1**（完全同步） | 20.0% | 毫无帮助——等于买了"同一只股票" |
| **0**（无关） | **14.1%** | 风险降了 29%！(= 20%/√2) |
| **−1**（完全反向） | **0%** | 风险被完全抵消！ |

**这就是分散投资的数学本质**：只要两个资产不是完全同步（ρ<1），把它们组合起来，**风险就低于各自风险的加权平均**。你**没有牺牲预期收益**（收益还是加权平均），却降低了风险——这是金融里少有的、近乎"凭空"的好处。诺奖得主马科维茨因此说：

> **"分散化是投资中唯一的免费午餐。"**

代码实验②把它画成"风险-收益"平面上的曲线（**马科维茨子弹**）：相关性越低，曲线越往左凸，意味着同样的收益你能用更低的风险拿到。这条边界就是路线 C 的主角——**有效前沿**。

## 五、一个惊艳的几何视角：相关性 = 夹角的余弦

这是给你（有数理直觉的人）的彩蛋，也是线代与统计最美的一座桥。

把每个资产的"去均值收益序列"看成一个**高维向量**（每一天是一个维度）。那么：

$$\rho_{AB} = \cos\theta_{AB}$$

**两个资产的相关系数，就是它们收益向量夹角的余弦！**

- 夹角 0°（同向）→ cos = 1 → 完全正相关。
- 夹角 90°（正交/垂直）→ cos = 0 → 不相关。
- 夹角 180°（反向）→ cos = −1 → 完全负相关。

于是"分散投资"有了一句极漂亮的几何说法：**别让你的持仓向量都指向同一个方向。** 找一些"互相垂直"（不相关）甚至"反向"（负相关）的资产，组合起来才稳。

> 代码实验③把它可视化：不相关的两资产收益散点是**圆形云**（各方向均匀），强相关的是**雪茄形云**（挤向一条对角线）。云的形状 = 相关性 = 夹角。**风险不是简单相加，是带着"夹角"几何地合成的。**

## 六、PCA / 特征值：从一篮子里提取「市场因子」

最后一块：协方差矩阵的**特征值/特征向量**能告诉我们市场的"主要运动方向"。

代码实验④造了 8 只都受"同一个大盘"影响的股票（$r_i = \beta_i F + \varepsilon_i$）。对它们的协方差矩阵做特征分解：

> **最大的特征值，一家就占了总方差的 55%。** 它对应的方向就是"**市场因子**"——大盘涨大家一起涨的那个共同力量。剩下的小特征值，才是各只股票自己的故事。

这就是**主成分分析（PCA）**和**因子模型**的雏形：用几个"主方向"（市场因子、行业因子、风格因子）解释一大堆资产的共同波动，把高维问题压缩成低维。路线 C / D 会深入。

> 🔬 物理类比：这和你在力学里找"主轴"、在简正模式里找"独立振动方向"是**同一套数学**（对称矩阵的特征分解）。协方差矩阵的特征向量 = 市场的"简正模式"。

## 七、思维模型

1. **组合 = 向量，风险结构 = 矩阵**：从"逐个分析"升级到"整体运算"。资产再多，记号不变。
2. **风险带"夹角"合成，不是相加**：相关性 = 余弦。分散 = 找不同方向的资产。
3. **免费午餐**：唯一不靠预测、靠"结构"就能改善风险收益的办法。先把分散做好，再谈选股择时。
4. **降维 / 抓主成分**：纷繁的市场背后，往往几个因子（主方向）解释了大部分波动。学会找"主轴"。

## 八、哲学指导与局限：协方差是最不可靠的输入

线性代数的运算是精确的，但喂给它的**协方差是估出来的，而且极不可靠**。这是组合管理最大的暗礁：

- **相关性会突变**：平时不相关的资产，**危机时一起暴跌**（相关性齐刷刷冲向 +1）。**分散化恰恰在你最需要它的时候失效**——2008 年血的教训。
- **估计噪声大 / 维度诅咒**：500 个资产的协方差矩阵有约 12 万个数要估，历史数据远远不够，估出来的矩阵充满噪声。"垃圾进，垃圾出"，再漂亮的优化也救不了烂的 Σ。
- **历史 ≠ 未来**：协方差用过去算，但未来的联动可能完全不同。

> 所以态度还是那句[谦逊](../../../docs/03-哲学与历史背景.md)：$\mathbf{w}^\top\Sigma\mathbf{w}$ 的数学是对的，但 $\Sigma$ 是个**会骗你的估计**。高手把大量精力花在"如何稳健地估计和压缩协方差"（收缩估计、因子模型），而不是迷信优化器吐出的"最优组合"。**模型是地图，相关性是会变的地形。**

## 九、方法论：先几何直觉，再矩阵运算

学线性代数，**千万别从抽象的矩阵乘法定义入手**（很多人就死在这）。正确顺序：
1. 先建**几何直觉**（向量是箭头、点积是投影、相关是夹角）——强烈推荐 3Blue1Brown《线性代数本质》（[资源清单](../../../docs/04-权威资源清单.md)）。
2. 再把直觉对应到**矩阵运算**（Σ、wᵀΣw、特征分解）。
3. 最后**亲手用代码算一遍**（就像本课）。

你有物理背景，对"向量、主轴、简正模式"本就熟悉——**这是你的优势，用几何直觉去理解金融的协方差，会比纯数学背景的人更快。**

## 十一、本课小结（费曼版）

- 线性代数 = 一次处理一篮子资产。**组合 = 权重向量，组合收益 = 点积 w·r。**
- **协方差矩阵 Σ = 风险的结构**；组合方差 = $\mathbf{w}^\top\Sigma\mathbf{w}$（整个组合理论的核心公式）。
- **分散投资是唯一的免费午餐**：只要相关性 < 1，组合风险就低于加权平均；相关性 = 收益向量**夹角的余弦**。
- **PCA/特征值**：协方差矩阵的最大特征值 = **市场因子**，是因子模型与降维的雏形。
- **最大的坑**：Σ 是不可靠的估计，相关性在危机时齐冲 +1，分散化会在最需要时失效。
