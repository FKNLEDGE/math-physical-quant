## Python 路线（先学这个）

| 阶段 | 内容 | ⭐ 首选资源 |
|---|---|---|
| **1. Python 基础** | 语法、列表/字典、函数、面向对象 | 廖雪峰 Python 教程 / 官方教程 |
| **2. 科学计算三件套** | **NumPy**(数组) · **Pandas**(表格/时序) · **Matplotlib**(画图) | [10分钟入门pandas](https://pandas.pydata.org/docs/user_guide/10min.html) · [NumPy新手](https://numpy.org/doc/stable/user/absolute_beginners.html) |
| **3. 数据获取与清洗** | 行情数据、缺失值、对齐、复权 | AKShare（国内）/ yfinance（海外） |
| **4. 回测与策略** | 自己写简易回测 → vectorbt | 见 [资源清单·第4节](../../docs/04-权威资源清单.md) |

> 💡 三件套是量化编程的 80%。把 NumPy 向量化和 Pandas 的 `DataFrame` 玩熟，比学十个框架都管用。

## C++ 路线（后期，遇到「太慢了」再学）

| 内容 | 用途 |
|---|---|
| C++ 基础 + 现代特性 | 性能关键的计算核心 |
| pybind11 | 让 Python 调用你的 C++（混编） |
| QuantLib | 衍生品定价权威库，C++ 核心，正好练手 |

> ⚠️ 别过早学 C++。先用 Python 把策略跑通，遇到真实的速度瓶颈（比如逐 tick 回测太慢）再上 C++ 优化热点。**过早优化是浪费。**

## 编程心法（量化特供）

- **向量化优先**：能用 NumPy/Pandas 一次算一整列，就别写 for 循环——又快又少 bug。
- **可复现**：固定随机种子、记录数据版本，保证「同样代码跑出同样结果」。
- **小步验证**：每写一小段就 print/画图看一眼，别憋一大坨再 debug。
