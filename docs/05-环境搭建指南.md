# 环境搭建指南

> 目标：在你自己的电脑上，**10～30 分钟内**配好环境，跑通第一行量化代码。
> 小白请走「推荐路线（Miniconda）」，它最省心。

---

## 一、推荐路线：Miniconda（小白首选）

Conda 能同时管理 **Python 版本** 和 **科学计算库**，还能隔离不同项目，最适合数据科学/量化。

### 1. 安装 Miniconda
- 去官网下载对应系统的安装包：<https://docs.conda.io/projects/miniconda/>
- Windows：双击安装，勾选「Add to PATH」（或之后用 Anaconda Prompt）。
- macOS / Linux：下载 `.sh` 后在终端 `bash Miniconda3-xxx.sh`，一路回车 + yes。

> 🌏 国内网络慢的话，可改用清华镜像（搜索「清华 anaconda 镜像」配置 `.condarc`），或直接用下面的 pip + 清华源方案。

### 2. 创建本项目专属环境
```bash
# 创建一个名叫 quant、用 Python 3.11 的隔离环境
conda create -n quant python=3.11 -y

# 激活它（以后每次学习前都先激活）
conda activate quant
```

### 3. 安装核心库
在项目根目录下：
```bash
pip install -r requirements.txt
```

---

## 二、备选路线：系统 Python + venv

已经装了 Python（3.10+）的话，也可以用自带的 `venv`：
```bash
# 在项目根目录
python -m venv .venv

# 激活：Windows
.venv\Scripts\activate
# 激活：macOS / Linux
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```
> 国内提速：在 `pip install` 后加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`

## 三、核心库都是干嘛的

| 库 | 作用 | 一句话 |
|---|---|---|
| **numpy** | 数值数组运算 | 量化的「计算引擎」，向量化运算的基础 |
| **pandas** | 表格 / 时间序列 | 处理行情数据的主力，`DataFrame` 就是你的「带索引的 Excel」 |
| **matplotlib** | 画图 | 把数据变成图，量化第一直觉来自看图 |
| **scipy** | 科学计算 | 统计分布、优化、积分等 |
| **jupyterlab** | 交互式笔记本 | 边写代码边看结果边记笔记，小白最友好 |
| **yfinance** | 免费行情数据 | 一行代码下载股票历史数据（练手用） |

> C++ 工具链（pybind11、CMake 等）等到[路线图](01-学习路线图.md)后期遇到性能瓶颈再装，现在不用管。

## 五、✅ 验证：跑通这段就算成功

新建文件 `检查环境.py`（或在 Jupyter 里跑），内容见项目里的 [`量化/第01课-量化是什么/`](../量化/第01课-量化是什么/)。最小验证：

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

print("numpy :", np.__version__)
print("pandas:", pd.__version__)
print("一切就绪！🎉")

# 画一条简单的随机游走（模拟一段「股价」），能弹出图就说明画图也 OK
np.random.seed(0)
price = 100 + np.cumsum(np.random.randn(250))
pd.Series(price).plot(title="一段模拟的随机游走价格")
plt.show()
```
能打印版本号、并弹出一张折线图，环境就配好了。看不到图、或报错，回头检查库是否装全、是否激活了环境。

## 六、常见坑

- **`ModuleNotFoundError`**：库没装，或没激活对应环境。先 `conda activate quant`（或 `source .venv/bin/activate`）再 `pip install`。
- **下载慢/超时**：换国内镜像源（清华 / 阿里）。
- **`yfinance` 拉不到数据**：可能是网络或接口变动，先用上面的「模拟随机游走」练手，行情数据后面专门讲怎么获取。
- **画图不显示**：脚本里记得 `plt.show()`；Jupyter 里加 `%matplotlib inline`。
