## 一、收益与风险

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 收益率 | return | 涨跌了百分之几（而非价格本身）。`> 第03课` |
| 对数收益率 | log return | `ln(今价/昨价)`，**可加**、更近正态，量化常用。`> 第03课` |
| 波动率 | volatility | 价格颠簸的剧烈程度，用收益率的标准差度量。`> 第03课` |
| 年化 | annualized | 把日/月数据换算成"一年"的口径；波动率年化乘 √252。`> 第03课` |
| 夏普比率 | Sharpe ratio | 每承担 1 单位风险换来多少超额收益；量化最核心单一指标，>1 算不错。`> 第03课` |
| 最大回撤 | max drawdown | 从历史最高点跌下来最惨的一次，决定你"拿不拿得住"。`> 第03课` |
| 净值（曲线） | equity curve | 1 块本金随时间长成多少；量化报告标配图。`> 第03课` |
| 基点 | bp (basis point) | 万分之一（1bp=0.01%）；常用于利率、手续费。`> 第04课` |
| 无风险利率 | risk-free rate | 国债那种"几乎稳赚"的利率，做基准用。`> 第03课` |
| 在险价值 | VaR | "正常情况下最多亏多少"的统计估计；在厚尾下会低估风险。`> E1` |

## 二、策略与交易

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 回测 | backtest | 假设当年就按这套规则交易，看历史表现；量化的"对照实验"。`> 第04课` |
| 基准 | benchmark | 比较的"笨参照"（如买入持有/指数）；跑不赢它的策略无意义。`> 第04课` |
| 买入持有 | buy & hold | 啥也不干、一直拿着；最该被打败的基准。`> 第04课` |
| 趋势跟踪 | trend following | 赌"涨的继续涨"，如均线策略。`> 第04课` |
| 均值回归 | mean reversion | 赌"涨多了会跌回来"。`> 时间序列课` |
| 动量 | momentum | 价格的"惯性"，近期强势倾向延续。`> 时间序列课` |
| 信号 / 持仓 | signal / position | 买/卖/空仓的决策（常用 0/1 或 ±1 表示）。`> 第04课` |
| 换手 | turnover | 调仓的频繁程度；越高交易成本越吃利润。`> 第05课` |
| 滑点 | slippage | 实际成交价比预期差的那部分，真实摩擦之一。`> 第05课` |
| 阿尔法 | alpha | 跑赢基准/Beta 的那部分超额，"真本事"（也可能是运气）。`> C2` |
| 贝塔 | beta | 对市场的敏感度（市场动 1%，你动多少）= 系统性风险。`> C2` |

## 三、量化的"诚实"陷阱（最重要）

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 过拟合 | overfitting | 模型背下了历史的噪声，对未来没用；头号杀手。`> 第05课 / D1` |
| 前视偏差 | look-ahead bias | 回测里偷用了当时还不知道的未来信息。`> 第05课` |
| 幸存者偏差 | survivorship bias | 只用"现在还活着的"标的，自动偏好结果。`> 第05课` |
| 数据窥探 | data snooping | 试了太多策略/参数，挑出的"最好"多半是运气。`> 第05课 / 概率课` |
| 样本内/外 | in/out-of-sample | 训练用的数据 / 没参与训练的检验数据。`> 第05课 / D1` |
| 走向前验证 | walk-forward | 永远用过去训练、未来测试，滚动前进；时序的正确验证法。`> D4` |
| 紧缩夏普 | deflated Sharpe | 按"你试了多少次"把观察到的最高夏普打折，扣掉运气。`> D4` |

## 四、衍生品（路线 B）

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 期权 | option | 一份"权利非义务"：看涨=有权买，看跌=有权卖。`> B1` |
| 行权价 | strike (K) | 期权约定的买/卖价格。`> B1` |
| 无套利 | no-arbitrage | 市场不存在"无风险零成本稳赚"；定价的地基。`> B1` |
| 看跌看涨平价 | put-call parity | `C+Ke⁻ʳᵀ=P+S₀`，纯逻辑锁住看涨/看跌价。`> B1` |
| 复制 | replication | 用股票+现金造出与期权相同的收益→期权价=复制成本。`> B2` |
| 风险中性 | risk-neutral | 一个"假装无人怕风险"的计算世界，价格=折现期望。`> B2` |
| Black-Scholes | —— | 期权定价的传奇公式，二叉树取极限的结果。`> B3` |
| 希腊字母 | Greeks | 期权价对各因素的敏感度（Delta/Gamma/Vega/Theta/Rho）=各种导数。`> B3` |
| 隐含波动率 | implied volatility | 从市场期权价反解出的波动率；呈"微笑"说明 BS 假设破了。`> B3` |
| 蒙特卡洛 | Monte Carlo | 模拟海量未来路径取平均来定价；万能但慢(误差~1/√N)。`> B4` |

## 五、组合与因子（路线 C）

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 分散投资 | diversification | 组合不完全同涨同跌的资产来降风险；"唯一的免费午餐"。`> C1` |
| 协方差矩阵 | covariance matrix Σ | 资产两两怎么联动；风险的结构。`> 线代课` |
| 有效前沿 | efficient frontier | 风险-收益平面上"同风险收益最高"的边界。`> C1` |
| CAPM | —— | 预期收益只由 Beta 决定的均衡模型。`> C2` |
| 系统性/特异风险 | systematic/idiosyncratic | 躲不掉的市场风险 / 可分散掉的个股风险。`> C2` |
| 因子模型 | factor model | 收益=对多个共同因子(市场/规模/价值…)的暴露。`> C3` |
| 风险平价 | risk parity | 不估收益，只让每个资产风险贡献相等。`> C4` |
| 收缩估计 | shrinkage | 把噪声大的样本协方差朝稳定目标"收缩"，更稳健。`> C4` |

## 六、统计与机器学习

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 大数定律 | LLN | 样本越多，平均越接近真值（噪声被平均掉）。`> 概率课` |
| 中心极限定理 | CLT | 大量独立随机量的平均趋于正态。`> 概率课` |
| 假设检验 / p值 | hypothesis test | 判断"是真信号还是运气"；p<0.05 才算证据够。`> 概率课` |
| t 统计量 | t-stat | 衡量显著性；经验法则 `t≈夏普×√年数`。`> 概率课` |
| 偏差-方差 | bias-variance | 模型太简单(欠拟合)还是太复杂(过拟合)的权衡。`> D1` |
| 泛化 | generalization | 在没见过的新数据上也准（而非背训练集）。`> D1` |
| 正则化 | regularization | 给复杂度加惩罚，防过拟合。`> D1` |
| 随机森林/梯度提升 | RF / gradient boosting | 树模型的集成；Bagging降方差/Boosting降偏差。`> D3` |
| 特征/标签 | feature / label | 输入的预测变量 / 想预测的目标。`> D1` |

## 七、数学物理 / econophysics（路线 E）

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 布朗运动 | Brownian motion | 连续的随机游走；股价模型的基础（=爱因斯坦的扩散）。`> 随机过程课` |
| 几何布朗运动 | GBM | 让"对数价格"做布朗运动→股价模型。`> 第01课 / 随机过程课` |
| 伊藤引理 | Itô's lemma | 随机版的链式法则，因 (dW)²=dt 多一项。`> 随机过程课` |
| 厚尾 | fat tails | 极端涨跌远比正态频繁；真实市场的常态。`> E1` |
| 幂律 | power law | `P(>x)~x⁻ᵅ`，无特征标度；复杂系统的指纹。`> E1` |
| Hurst 指数 | Hurst exponent | 度量长程记忆：>0.5趋势、<0.5回归、=0.5随机。`> E2` |
| 相变/临界 | phase transition | 系统在临界点突变，涌现幂律涨落；崩盘的物理。`> E3` |
| 自组织临界 | SOC | 系统自发演化到临界态(沙堆)，无需精调。`> E4` |
| 涌现 | emergence | 简单微观规则→复杂宏观行为("More is different")。`> E4` |

## 八、市场机制（基础常识）

| 中文 | 英文 | 一句话人话 |
|---|---|---|
| 做多/做空 | long / short | 赌涨(先买后卖) / 赌跌(先借券卖、跌了买回还)。 |
| OHLCV | —— | 开/高/低/收/成交量，行情数据标准五列。`> 第02课` |
| 复权 | adjusted price | 抹平分红/拆股造成的假跳空，研究必用。`> 第02课` |
| 流动性 | liquidity | 能多快、多便宜地买卖而不大幅移动价格。 |
| 多空/市场中性 | market-neutral | 同时做多做空、对冲掉市场涨跌，只赚相对。 |
| 杠杆 | leverage | 借钱放大头寸；放大收益也放大风险与爆仓概率。 |
