# 哲学与历史背景

> 公式会过时，但「人类是怎么一步步学会给不确定性定价的」这段思想史不会。
> 这份文档回答三个问题：**量化从哪来？市场的本质是什么？物理和金融为什么是表亲？**
> 对你（有物理底子的学习者）尤其重要——你会发现自己已经掌握的很多工具，正是量化的核心。

---

## 一、一条主线：人类如何学会给「不确定性」定价

### 🕰️ 关键时间线

| 年份 | 人物 | 事件 | 为什么重要 |
|---|---|---|---|
| **1900** | **Louis Bachelier**（巴施里耶） | 博士论文《投机理论》，用**布朗运动**为期权定价 | 量化金融的真正起点，**比爱因斯坦早 5 年**用到布朗运动；当时被忽视 |
| 1905 | **Einstein**（爱因斯坦） | 用布朗运动解释花粉颗粒的随机游走 | 物理学独立「重新发现」了同一个数学——金融与物理的第一次隐秘交汇 |
| 1923 | **Norbert Wiener**（维纳） | 给布朗运动严格的数学定义（维纳过程） | 把直觉变成可证明的数学 |
| 1944 | von Neumann & Morgenstern | 《博弈论与经济行为》、期望效用理论 | 「理性决策」有了数学框架 |
| **1952** | **Harry Markowitz**（马科维茨） | 现代组合理论（MPT）：用**均值-方差**量化「分散投资」 | 第一次把「风险」精确化为方差，"不要把鸡蛋放一个篮子"有了数学。后获诺奖 |
| 1958/64 | **William Sharpe** 等 | 资本资产定价模型（CAPM），提出 **Beta** | 把单只资产的预期收益和市场风险联系起来 |
| 1965 / **1970** | **Eugene Fama**（法马） | 有效市场假说（EMH）：1965 年系列论文，1970 年奠基性综述《Efficient Capital Markets》 | 「价格已反映所有信息，你赚不到超额收益」——量化要么反对它、要么利用它的裂缝。2013 年获诺奖 |
| 1960s | **Edward Thorp**（索普） | 数学家：先用概率破解 21 点（《打败庄家》），再做可转债套利 | **第一个真正意义上的「宽客」**，证明了数学能在市场赚钱 |
| **1973** | **Black, Scholes, Merton** | Black-Scholes-Merton 期权定价公式 | 量化的「牛顿定律」时刻；同年芝加哥期权交易所开市。后获诺奖 |
| 1982 | **Jim Simons**（西蒙斯） | 数学家创立文艺复兴科技，旗下 **Medallion 基金** | 雇物理学家/数学家/密码学家，成为史上最赚钱的基金，宽客的「圣殿」 |
| 1987 | —— | 「黑色星期一」，组合保险等程序化交易加剧崩盘 | 第一次「模型/程序」被指放大系统性风险 |
| 1990s | Mantegna, Stanley 等 | **经济物理学（Econophysics）** 兴起 | 物理学家用统计力学方法研究市场，发现「厚尾」「幂律」 |
| **1998** | —— | 长期资本管理公司（**LTCM**）崩盘 | 两位诺奖得主在内、模型精密的基金几周内爆掉——**模型风险**的世纪教训 |
| 2007–08 | —— | 「宽客地震」与全球金融危机 | 复杂衍生品模型低估尾部风险，模型的局限被血淋淋地暴露 |
| 2010s→ | —— | 机器学习、另类数据、高频交易（HFT） | 算力与数据爆炸，竞争转向「谁的数据/模型更好、更快」 |

> 📌 记住这条线的「精神」：每一次大进步（Bachelier→Markowitz→BSM）都是**把一种模糊的金融直觉，翻译成精确的数学**；而每一次大灾难（LTCM、2008）都是**人们忘了「模型只是地图，不是疆域」**。

## 二、物理与金融：一对隐秘的表亲 🔬💹

> 这一节是给你（学物理的人）的福利。量化里大量「高大上」的工具，其实就是你已经见过的物理。

### 1. 布朗运动：从花粉到股价
- 1827 年植物学家布朗在显微镜下看到花粉颗粒乱动；1905 年爱因斯坦用**扩散**解释它。
- 而**早 5 年**，Bachelier 已经用同样的数学描述股价的随机游走。
- 今天量化建模股价的标准起点——**几何布朗运动**——就是这套数学的直系后代。

### 2. Black-Scholes 方程 = 热传导/扩散方程
量化里最著名的 Black-Scholes 偏微分方程，经过一次变量替换，**就变成物理里的热传导方程**（diffusion equation）：

$$\frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0 \;\;\xrightarrow{\text{换元}}\;\; \frac{\partial u}{\partial \tau} = \frac{\partial^2 u}{\partial x^2}$$

你在《数学物理方法》里解过的热方程，换身衣服就成了期权定价。**这不是巧合，是同一个「随机扩散」数学结构。**

### 3. 更多对应关系
| 物理概念 | 金融对应 |
|---|---|
| 热/扩散方程 | 期权定价（Black-Scholes） |
| 随机游走 / 朗之万方程 | 价格过程、几何布朗运动 |
| 统计力学（系综、配分函数） | 大量交易者的集体行为、风险中性测度 |
| 路径积分（费曼） | 衍生品定价的路径积分法（Dash, Bouchaud） |
| 相变、临界现象、幂律 | 市场崩盘、厚尾分布、波动率聚集 |
| 涨落-耗散、关联函数 | 波动率、自相关、协方差结构 |

### 4. 物理学家为什么统治了华尔街
1980s 起，大批物理学博士（找不到教职）涌入华尔街，被称为「宽客（quants）」。原因很直接：**他们早就会随机过程、偏微分方程、数值模拟、从噪声数据里提取规律**——这正是定价和建模需要的。
- **Emanuel Derman**：理论物理学家 → 高盛，著有《宽客人生（My Life as a Quant）》，强烈推荐，是「物理 → 金融」这条路最好的第一人称记录。
- **Jean-Philippe Bouchaud**：物理学家，创立 Capital Fund Management，把统计物理用到金融，著有 econophysics 经典。
- **Jim Simons**：拓扑学/几何学大师 → 文艺复兴科技。

> 给你的启示：你担心「农学背景 + 物理基础够不够做量化」——历史的答案是：**物理思维恰恰是量化最稀缺的底层能力之一**。你缺的只是金融语境和编程手感，这两样这个项目会帮你补。

## 三、市场的哲学：我们到底能不能预测？

量化的全部张力，来自一个根本的哲学争论。理解这场争论，比记住任何公式都重要。

### 🟦 正方：有效市场假说（EMH，Fama）
价格已经反映了所有可得信息，所以**没人能持续跑赢市场**，超额收益只是运气。
- 若 EMH 完全成立，主动量化就没意义，老老实实买指数即可。

### 🟥 反方与修正

**1. 行为金融学**：人不理性（贪婪、恐惧、羊群效应），会系统性地犯错，于是出现可被利用的规律（动量、反转）。Kahneman、Shiller 是代表。

**2. 适应性市场假说（Andrew Lo）**：市场像生态系统，规律会随参与者进化而出现、被利用、然后消失。**没有永恒的圣杯，只有不断适应**——这也解释了为什么策略会「失效」。

**3. Mandelbrot 的厚尾批判**：主流模型假设收益服从正态分布，但 Mandelbrot（分形几何之父）指出，真实市场是**厚尾**的——极端事件（崩盘）远比正态分布预测的频繁。用正态分布做风控，等于系统性地低估灾难。

**4. Taleb 的黑天鹅**：延续 Mandelbrot。我们对「极端罕见但影响巨大」的事件几乎无法预测，却总在事后假装早该知道。
- **黑天鹅**：不可预测、影响巨大、事后被合理化的事件。
- **反脆弱（Antifragile）**：与其预测黑天鹅，不如把自己的仓位构造成「波动越大、混乱越多，反而越受益」。
- **遍历性（Ergodicity）**：「一群人各赌一次的平均结果」≠「一个人连续赌很多次的结果」。一个时间平均会让你爆仓的游戏，哪怕系综平均是正的，也不能玩。这是风险管理最深刻的洞见之一。

### ⚖️ 一个务实的综合立场
本项目推荐这样看待这场争论：
- 市场**大体有效**，所以**轻松的钱不存在**，任何「稳赚」的想法先默认它是错的。
- 但市场**并非完全有效**，存在**短暂的、会被竞争磨平的**结构性机会。
- 量化的工作 = **用严谨的方法，在噪声的海洋里找到那一点点真实且暂时的信号，并在它消失前管好风险。**

## 四、三条要刻进骨子里的哲学

1. **谦逊（Humility）**：市场比你聪明。你的模型几乎肯定在某处是错的。带着「我可能错了」交易的人活得更久。
2. **风险优先于收益**：先想「最坏能亏多少、会不会爆仓」，再想「能赚多少」。活下来才能复利。（呼应[遍历性](#)与[复利不对称](02-方法论与思维模型.md)）
3. **科学的诚实**：诚实地设计可证伪的假设，诚实地面对样本外的失败。**骗得了回测，骗不了实盘。** 在量化里，自我欺骗的代价是真金白银。
