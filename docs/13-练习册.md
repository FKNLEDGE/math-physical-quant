## 第三部分:编程练习(改/扩现有代码)

> 💻 这些都建立在已有模块的代码上,改一改、跑一跑,看结果怎么变。

14. 🟢 把 [均线交叉策略](../量化/第04课-第一个策略-均线交叉/) 的快慢窗口从 (20,60) 改成 (5,20) 和 (50,200),对比夏普和最大回撤。哪个更好?这说明了什么(关于参数挑选)?
15. 🟢 跑 [B4 蒙特卡洛定价](../量化/路线B-衍生品定价/04-蒙特卡洛定价/),把路径数从 1万 加到 100万,看价格如何收敛到 Black-Scholes、误差如何按 1/√N 缩小。
16. 🟡 在 [Heston②](../量化/进阶-物理味进阶/02-随机波动率Heston/) 里把相关系数 ρ 从 −0.6 改成 +0.6,看波动率微笑的**偏斜方向**怎么翻转。解释为什么。
17. 🟡 在 [Kalman②](../量化/进阶-统计套利与协整/02-Kalman动态对冲/) 里把 `delta`(过程噪声)调大 100 倍,看 β 估计变多"抖"、夏普怎么变——亲手体会偏差-方差。
18. 🟡 在 [特征重要性③](../量化/进阶-金融机器学习进阶/03-特征重要性陷阱/) 里把随机森林的 `max_depth` 设回 6、`min_samples_leaf=20`(正则化),看 MDI 给噪声的分是不是大降。**过拟合是 MDI 噪声陷阱的元凶**,验证它。
19. 🔴 给 [C++ 模块](../量化/进阶-编程深化/01-CPP加速蒙特卡洛/) 的 `mc_pricer.cpp` 加一个**亚式期权**(payoff 用路径**均值**而非终值)的定价函数,用 pybind11 绑定,从 Python 调用并对比 NumPy 版速度。
20. 🔴 在 [综合实战①](../量化/进阶-综合实战/01-端到端诚实流水线/) 里,把执行成本 `COST` 从 8bp 改成 0 和 30bp,看"诚实瀑布"最后一根柱子怎么动。再把 `purge=True` 改 `False`,量化"重叠泄露"贡献了多少虚高夏普。

## 怎么给自己打分

- **概念题**:能不看笔记、用大白话讲清楚 = 过。
- **手推题**:能独立推到答案,且能解释每一步"为什么" = 过。
- **编程题**:能跑通、能解释结果变化的**原因** = 过;能进一步提出"那如果……会怎样"= 优秀。
- **综合挑战**:没有标准答案。**思路完整 + 诚实面对负结果 = 满分。**

> 🎓 **最后一句**:这门课最难的不是数学,是**诚实**——对数据诚实、对自己的策略诚实、对"我其实没赚到钱"诚实。
> 把这份练习册做完,你收获的不只是技能,更是一种**先怀疑自己**的科学态度。这,比任何 alpha 都值钱。
