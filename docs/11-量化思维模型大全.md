# 量化思维模型大全

> 知识会过时，**思维模型**不会。这份文档把散落在各课里的思维模型**汇成一件趁手的武器**，
> 并补上几个更进阶的。每个模型：**一句话本质 + 量化例子 + 出现在哪课**。
> 用法：决策卡壳时，从头扫一遍这张清单，问"我漏了哪个视角？"

> 🧭 这是 [docs/02 方法论与思维模型](02-方法论与思维模型.md) 的"全集进阶版"。

## 一、概率与不确定性

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **概率思维** | 世界不是"会/不会"，而是"多大概率" | 把市场直觉翻译成可计算的分布（[第01课](../量化/第01课-量化是什么/)） |
| **期望值思维** | 决策看 `Σ(概率×结果)`，不是单次输赢 | 胜率40%但盈亏比3:1长期赚（[A+1](../量化/路线A+实战进阶/01-仓位管理与资金管理/)） |
| **贝叶斯更新** | 有新证据就按比例更新信念，`后验∝似然×先验` | 看到"稳赚回测"，先验是"市场有效"→后验"多半错了" |
| **基率忽视** | 别忽略"背景概率" | 90%准确的"涨跌预测"，在50%基率噪声里几乎没用（[D2](../量化/路线D-机器学习量化/02-金融为何是机器学习地狱/)） |
| **信号 vs 噪声** | 金融信噪比极低，绝大多数波动是噪声 | 别在噪声里看出不存在的规律（[概率课](../基础/数学/概率统计-区分信号与噪声/)） |
| **风险 vs 不确定性**(Knight) | 概率已知=风险(可算)；未知=不确定(算不了) | 模型把"不确定"误当"风险"定价→2008（[E1](../量化/路线E-数学物理深化/01-厚尾与幂律/)） |
| **遍历性**(ergodicity) | 系综平均≠时间平均；你活在时间里 | 满仓正期望赌局,时间平均仍破产（[A+1](../量化/路线A+实战进阶/01-仓位管理与资金管理/)） |

## 二、风险与生存

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **凸性 / 不对称**(Taleb) | 找"下行有限、上行巨大"，避反过来 | 买期权(亏权利金,赚无限) vs 裸卖期权（[B1](../量化/路线B-衍生品定价/01-期权与无套利原理/)） |
| **复利的不对称** | 亏50%要赚100%才回本 | 控制回撤 > 追求高收益（[第03课](../量化/第03课-收益率与风险的语言/)） |
| **破产风险 / 下注规模** | 押太大,正期望也会破产 | Kelly 准则、分数Kelly（[A+1](../量化/路线A+实战进阶/01-仓位管理与资金管理/)） |
| **安全边际** | 给"我可能算错了"留余地 | 把成本加倍策略还活吗？厚尾留余地（[第05课](../量化/第05课-给策略祛魅/)、[E1](../量化/路线E-数学物理深化/01-厚尾与幂律/)） |
| **反脆弱** | 让仓位"越混乱越受益" | 凸性结构、波动率多头（[哲学课](03-哲学与历史背景.md)） |
| **风险优先于收益** | 先想最坏能亏多少,再想能赚多少 | 风险平价、熔断（[C4](../量化/路线C-组合管理/04-风险平价与实务脆弱性/)、[A+4](../量化/路线A+实战进阶/04-从回测到模拟盘/)） |
| **生存即胜利** | 活着才能复利;别出局 | "宁可少赚,不可出局"（[A+1](../量化/路线A+实战进阶/01-仓位管理与资金管理/)） |

## 三、认识论与防自欺（量化的命脉）

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **模型是地图不是疆域**(Box) | 所有模型都错,但有些有用;关键是知道它何时失效 | BS常波动率假设(微笑)、CAPM(异象)（[B3](../量化/路线B-衍生品定价/03-BlackScholes公式/)、[C2](../量化/路线C-组合管理/02-CAPM与Beta/)） |
| **过拟合** | 完美解释过去=学了噪声 | 偏差-方差、紧缩夏普（[D1](../量化/路线D-机器学习量化/01-监督学习与偏差方差权衡/)、[D4](../量化/路线D-机器学习量化/04-诚实的ML策略与现实/)） |
| **多重检验 / 数据窥探** | 试得越多,越易撞出假信号 | 测500个策略,挑最好的多半是运气（[概率课](../基础/数学/概率统计-区分信号与噪声/)、[C3因子动物园](../量化/路线C-组合管理/03-因子模型/)） |
| **前视 / 后视偏差** | 偷用未来 / 事后假装早知道 | 信号必须shift、全样本统计量泄漏（[第05课](../量化/第05课-给策略祛魅/)、[D2](../量化/路线D-机器学习量化/02-金融为何是机器学习地狱/)） |
| **可证伪性**(Popper) | 好假设必须能被明确打脸 | 规定"什么结果算我错了"再去测（[方法论](02-方法论与思维模型.md)） |
| **叙事谬误** | 大脑爱给随机编故事 | 崩盘后总能"找到原因"(其实内生)（[E3](../量化/路线E-数学物理深化/03-崩盘作为相变/)） |
| **过程 > 结果** | 单次结果有运气,好流程才可复现 | 诚实的"不行"胜过自欺的"行"（[A+2](../量化/路线A+实战进阶/02-端到端实战项目/)） |
| **交叉验证(自我)** | 两种独立方法对得上才信 | 事件驱动 vs 向量化结果一致（[A+3](../量化/路线A+实战进阶/03-正规回测框架入门/)） |

## 四、市场与系统

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **有效市场 + 适应性市场** | 大体有效(没轻松钱),但规律会随竞争出现-被利用-消失 | 优势微弱、暂时、会衰减（[哲学课](03-哲学与历史背景.md)、[C2 Alpha](../量化/路线C-组合管理/02-CAPM与Beta/)） |
| **优势衰减 / 拥挤** | 赚钱的人多了,优势被磨平甚至反转 | 因子拥挤、2007宽客地震（[C3](../量化/路线C-组合管理/03-因子模型/)、[简史](09-量化简史故事版.md)） |
| **涌现 / 临界**(复杂系统) | 简单微观规则→复杂宏观;系统自发逼近临界 | 羊群→相变→崩盘;自组织临界（[E3](../量化/路线E-数学物理深化/03-崩盘作为相变/)、[E4](../量化/路线E-数学物理深化/04-统计力学看市场收官/)） |
| **厚尾 / 幂律** | 极端事件远比正态频繁;无特征标度 | 5σ常见数千倍;VaR低估（[E1](../量化/路线E-数学物理深化/01-厚尾与幂律/)） |
| **机制转换 / 非平稳** | 世界会变;昨天的规律明天可能反转 | 回测最危险的敌人（[时间序列课](../基础/数学/时间序列-价格的记忆与平稳性/)） |
| **方向难测,波动可测** | 收益符号≈随机,幅度有结构 | 别预测收益,去预测风险（[时间序列课](../基础/数学/时间序列-价格的记忆与平稳性/)、[E2](../量化/路线E-数学物理深化/02-反常扩散Lévy与分形/)） |
| **反身性**(Soros) | 参与者的信念会反过来改变现实 | 泡沫的正反馈自我强化（[E3](../量化/路线E-数学物理深化/03-崩盘作为相变/)） |

## 五、第一性原理与迁移（你的物理主场）

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **第一性原理** | 追问到底层事实,再往上推 | 为什么用对数收益?→连续复利e^x（[第03课](../量化/第03课-收益率与风险的语言/)） |
| **同构 / 迁移**(抽象的力量) | 剥掉外衣,识别"换马甲的老朋友" | BS=热方程;协方差特征向量=简正模式（[B5](../量化/路线B-衍生品定价/05-BS与热方程的同构/)、[线代课](../基础/数学/线性代数-组合与协方差的几何/)） |
| **标度律 / 量纲** | 用"量怎么随尺度变"抓本质 | √t律、MSD∝t^2H、幂律指数（[随机过程课](../基础/数学/随机过程-从抛硬币到布朗运动/)、[E2](../量化/路线E-数学物理深化/02-反常扩散Lévy与分形/)） |
| **极限思想** | 离散取极限→连续的洞见 | 随机游走→布朗;二叉树→BS（[随机过程课](../基础/数学/随机过程-从抛硬币到布朗运动/)、[B2](../量化/路线B-衍生品定价/02-二叉树与风险中性/)） |
| **守恒 / 无套利** | "不能凭空生钱"是强约束 | 看跌看涨平价、复制定价（[B1](../量化/路线B-衍生品定价/01-期权与无套利原理/)、[B2](../量化/路线B-衍生品定价/02-二叉树与风险中性/)） |
| **系综 / 分布思维** | 关注可能性的全体,而非单条路径 | 风险中性期望、蒙特卡洛（[B2](../量化/路线B-衍生品定价/02-二叉树与风险中性/)、[B4](../量化/路线B-衍生品定价/04-蒙特卡洛定价/)） |

## 六、决策与执行

| 模型 | 一句话本质 | 量化例子 |
|---|---|---|
| **二阶思维** | 问"然后呢?"——别只看第一层后果 | 策略上线后会拥挤;加杠杆放大尾部 |
| **逆向思维**(inversion) | 不问"怎么成功",问"怎么必败",然后避开 | 诚实清单=列出所有让你亏钱的方式（[第05课](../量化/第05课-给策略祛魅/)） |
| **机会成本** | 选A=放弃B;算的是相对最优 | 跑不赢买入持有的策略毫无意义（[第04课](../量化/第04课-第一个策略-均线交叉/)） |
| **闯关而非开关** | 想法→真钱是逐级淘汰,不是一步到位 | 回测→模拟盘→小额→加仓（[A+4](../量化/路线A+实战进阶/04-从回测到模拟盘/)） |
| **即时学习 / 项目驱动** | 缺啥补啥,带着问题学 | 主线缺数学就回基础补一小块（[方法论](02-方法论与思维模型.md)） |
| **谦逊** | 市场比你聪明;你几乎肯定某处错了 | 带着"我可能错了"交易,活得更久（[哲学课](03-哲学与历史背景.md)） |

## 怎么用这张清单

1. **决策前扫一遍**：做一个"赚钱"判断前，从"防自欺"那栏逐条自问。
2. **复盘时对照**：亏了/错了，回来找"我漏了哪个模型"。
3. **跨界迁移**：遇到新问题，先问"它和我已知的哪个同构？"（你的物理优势）。
4. **内化**：真正的高手不是"知道"这些，而是它们成了**本能**。反复用，直到不用想。

> **一句话总收束**：量化的修养 = 用概率思维看世界 + 用第一性原理拆问题 + 用近乎偏执的诚实防自欺 + 把生存和谦逊放在赚钱之前。
