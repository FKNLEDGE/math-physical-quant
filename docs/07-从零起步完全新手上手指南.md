## 〇、先建立信心：你只需要会三件事

学量化的"动手"部分，本质只需要：**①装好 Python ②会运行一个文件 ③看懂报错去查**。
就这三件。下面一步步来，每步都有"你应该看到什么"。**遇到卡壳很正常，往下看「报错急救」。**

> 🌾 你是农学生——把这想成"学用一台新的实验仪器"。第一次摸不熟，跑通两三次就有肌肉记忆了。

## 一、三个名词，先用大白话说清

| 名词 | 它是什么（人话） | 类比 |
|---|---|---|
| **Python** | 一种编程语言，也是电脑上的一个"翻译官"程序，能读懂 `.py` 文件并执行 | 实验仪器本体 |
| **终端 / 命令行**（Terminal） | 一个黑框框，你打字命令、它执行。比鼠标点点更直接 | 仪器的控制面板 |
| **编辑器**（VS Code 等） | 写/看代码的"记事本 plus"，有高亮、能直接运行 | 实验记录本 |

记住：**`.py` 是代码文件，`.md` 是笔记文件（就是你正在读的这种）。**

## 二、装 Python（推荐 Miniconda，最省心）

1. 打开 <https://docs.conda.io/projects/miniconda/>，下载对应你系统（Windows / Mac）的安装包。
   - 🌏 国内慢就搜"清华 miniconda 镜像"下载。
2. 双击安装，**Windows 记得勾上 "Add to PATH"**（或之后用"Anaconda Prompt"这个黑框）。
3. 装完，打开终端：
   - **Windows**：开始菜单搜 `Anaconda Prompt`，打开。
   - **Mac**：`Command+空格` 搜 `Terminal`，打开。
4. 在黑框里输入下面这行，回车：
   ```bash
   python --version
   ```
   **你应该看到**类似 `Python 3.11.x`。看到了 → 成功！没看到/报错 → 见文末「报错急救」。

## 四、装依赖（一次性）

进到项目文件夹，在终端里跑：

## 六、怎么"运行一个文件"——万能套路

以后每一课都一样：
```bash
cd 路径/到/某一课的文件夹      # cd = 进入文件夹
python 文件名.py              # 运行它
```
- 不知道当前在哪？输 `pwd`（Mac）/ `cd`（Windows）看当前路径，`ls`（Mac）/ `dir`（Windows）看有哪些文件。
- 文件夹名有中文？没关系，直接打或用 Tab 键自动补全。

## 七、🚑 报错急救（最常见的 4 种）

代码报错**不可怕**，红字里藏着答案。先看**最后一行**：

| 报错关键词 | 意思 | 怎么修 |
|---|---|---|
| `ModuleNotFoundError: No module named 'xxx'` | 缺某个库 | 跑 `pip install xxx`（或回第四步装依赖）|
| `FileNotFoundError` / 找不到数据 | 路径不对/没在对的文件夹 | 确认你 `cd` 到了正确的课程文件夹再跑 |
| `python: command not found` | Python 没装好/没进 PATH | 回第二步；Windows 用 Anaconda Prompt |
| 图是方块/乱码 | 缺中文字体 | 正常，不影响；图内英文标签是故意的（讲解在笔记里）|

> 💡 万能一招：**把报错最后一行复制，粘到搜索引擎或问 AI**，99% 有现成答案。这是程序员每天都在做的事，不丢人。

## 八、怎么"学"——每节课的正确节奏

每一课都按这个循环（[方法论详解](02-方法论与思维模型.md)）：

1. **读笔记** `笔记.md`——先理解概念（不懂没关系，往下走）。
2. **跑代码**——`python xxx.py`，看输出和图，建立直觉。
3. **改一个参数**——把代码里某个数改了重跑，观察变化（这步最长本事！）。
4. **费曼复述**——合上笔记，用自己的话讲一遍刚学的。讲不清 = 没懂，回头再读。
5. **打勾**——在 [README 进度表](../README.md) 里标记完成。

> **节奏建议**：每天 1～1.5 小时、稳定推进 > 偶尔爆肝。一周吃透 2～3 课就很好。

## 十、卡住了怎么办

1. **报错** → 看第七步「报错急救」，复制最后一行去搜。
2. **概念不懂** → 先跳过往下走（很多概念后面会反复出现、自然就懂了），或回到该课的"最简单例子"和代码。
3. **完全没头绪** → 回到[第 01 课](../量化/第01课-量化是什么/)，它假设你什么都不会。
4. **遇到不认识的词** → 查[术语表](08-量化术语表.md)。

> **最重要的心态**：你不需要一次看懂所有东西。**先求会用（跑通+改参数），再求理解，最后求批判。** 允许自己"先囫囵跑通，回头再懂"。这才是学得动、学得久的方式。
