# 量化主线 🤖

> 这是小白的**主战场**。按[路线图](../docs/01-学习路线图.md)，量化基础为 0 的你从这里开始：
> 先获得「跑通一个策略」的手感和正反馈，再回头补数学、补严谨性。

---

## 这条线怎么走

我们沿着「一个真实策略的生命周期」推进，每一课都让你离「能独立做一个诚实的量化研究」更近一步：

```
量化是什么 → 拿到数据 → 算收益与风险 → 做一个最朴素的策略
   → 学会诚实地回测 → 给策略「祛魅」 → 选一条分支深入
```

## 课程目录

| 课 | 标题 | 你将学会 | 状态 |
|---|---|---|---|
| **01** | [量化到底是什么](第01课-量化是什么/) | 量化的本质、它能/不能做什么、跑通第一段代码 | ✅ 可学 |
| 02 | 拿到并看懂行情数据 | 用 pandas 读取、清洗、对齐价格数据 | 🔜 规划中 |
| 03 | 收益率与风险的语言 | 对数收益、波动率、夏普、最大回撤 | 🔜 规划中 |
| 04 | 第一个策略：均线交叉 | 生成信号、向量化回测、画净值曲线 | 🔜 规划中 |
| 05 | 给策略祛魅 | 交易成本、前视/幸存者偏差、样本内外 | 🔜 规划中 |

> 课程会随项目推进逐步补全。每一课都遵循「**概念（人话）→ 代码（手感）→ 费曼复述（检验）**」三件套。
