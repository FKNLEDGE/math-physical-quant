# 进阶·物理味 ⑥ Hawkes 生出粗糙波动率（rough vol 的微观起源）

> [④](../04-粗糙波动率/笔记.md) 量到"波动率是粗糙的(H≈0.1)",[⑤](../05-粗糙波动率定价rBergomi/笔记.md) 用它定价。但留了个最深的问题:**为什么偏偏是 0.1?**
> 这一课给微观答案:**粗糙波动率,源自自激 + 长记忆的订单流。** 它把 [③ Hawkes](../03-Hawkes自激过程/笔记.md) 和 [④ rough vol](../04-粗糙波动率/笔记.md) 焊在一起,
> 让物理味这条线**从微观订单流一路通到宏观期权微笑**。配套代码:[`hawkes_to_rough.py`](hawkes_to_rough.py)。

> 🧭 本质 → 微观机制 → 模拟看见 → 物理(涌现) → 闭环整条物理线。

---

## 一、本质（一句话）

> **宏观的"粗糙波动率",是微观"自激且长记忆的订单流"的涌现结果。** [③](../03-Hawkes自激过程/笔记.md) 说订单会自我激发、且市场近临界(n≈0.9);
> 一旦这种自激带上**长记忆(幂律核)**,聚合出的市场活动度(波动率)就**天然是粗糙的(H≈0.1)**——和 ④ 的实证完全对上。

---

## 二、微观机制:从"订单自激"到"波动率粗糙"

把两件已知的事接起来:

1. **订单流是自激的**([③ Hawkes](../03-Hawkes自激过程/笔记.md)):一笔成交触发更多成交,且实证**近临界**(分支比 n≈0.9)。
2. **订单流有长记忆**:真实订单流的激发核是**幂律**(t^{−(1+γ)})而非快速衰减的指数——影响拖得很长。

**Jaisson-Rosenbaum(2015–16)** 严格证明:**近临界 + 长记忆的 Hawkes 过程,在标度极限下,其活动度(波动率代理)收敛到一个【粗糙】过程(rough Heston)。** 也就是说:[④ 的粗糙](../04-粗糙波动率/笔记.md),不是凭空假设的,而是从订单流的微观结构**推导**出来的。

---

## 三、用模拟把机制"看见"

代码用**分支/簇表示**精确模拟幂律核近临界 Hawkes,再聚合出活动度,量它的 Hurst:

- **实验①②**([图①②](Hawkes生粗糙配图.png)):事件**剧烈成簇**(订单流爆发),聚合出的活动度路径**锯齿、粗糙**——肉眼就像 ④ 的 rough vol 路径。
- **实验③**:用**和 ④ 同一把尺**(增量矩标度)量活动度的 Hurst → **H≈0.12**,**正落在实证粗糙波动率 H≈0.1 的范围**!微观自激,真的生出了宏观粗糙。
- **实验④**([图④]):**幂律尾指数 γ 调节粗糙度**——尾越重(γ 越小)、记忆越长 → 活动度越粗糙(H 越小);γ≈0.7 时 H 恰好落在实证带里。**"为什么 H≈0.1"被推到了"订单流记忆有多长"这个更底层的问题。**

> ⚠️ **诚实边界**:这是**机制的定性演示**,不是严格极限的复现。精确的普适 H、以及分支比 n 对粗糙度的确切作用,需要 Jaisson-Rosenbaum 的严格标度论证(我的有限样本测量会受 bin 大小等影响)。**但"长记忆自激订单流 → 粗糙波动率、且 H 落在 0.1 附近"这个核心结论是稳健、可复现的**(代码里跨种子标准差很小)。

## 四、物理视角:涌现（emergence）

这一课是**涌现**的漂亮案例:

- **微观**:一个个离散的订单,按自激规则(Hawkes)发生。
- **宏观**:聚合起来,涌现出连续的、粗糙的(分数维)波动率过程。
- **桥梁**:近临界(n→1)让微观涨落不被抹平、长记忆(幂律)让它在所有尺度上保持粗糙——**临界 + 长记忆 = 标度不变的粗糙**(呼应 [E3 自组织临界](../../路线E-数学物理深化/03-崩盘作为相变/笔记.md))。

> **你在统计物理里建立的"微观规则 → 宏观涌现 / 临界标度"直觉,就是这一课的母语。** 这正是物理学家把金融当复杂系统研究的范式:不满足于"假设波动率粗糙",而要问"它从什么微观机制长出来"。

---

## 五、思维模型

1. **把"假设"换成"推导"**:④ 假设 vol 粗糙,这一课从订单流**推导**出粗糙。**好的科学不断把"输入假设"变成"输出结论"**(呼应 [Heston 把常波动内生化](../02-随机波动率Heston/笔记.md))。
2. **涌现 / 多尺度**:宏观性质(粗糙)不在任何单个微观个体里,而在它们的**集体 + 临界 + 长记忆**中。**别在错误的尺度找原因。**
3. **临界 + 长记忆 = 标度不变**:两者合起来,系统在所有时间尺度上都"自相似地粗糙"(分形)。
4. **把"为什么"往下推一层**:这一课没有终结"为什么 0.1",而是把它**翻译**成"订单流记忆有多长"——更底层、更可测的问题。**科学是层层下推的翻译。**

---

## 六、哲学指导

> **这一课完成了物理味这条线的大闭环:微观订单流(③ 自激)→ 宏观波动率(④ 粗糙)→ 期权价格(⑤ 微笑)。** 一条从"市场最底层的成交"到"交易员屏幕上的波动率曲面"的完整因果链,全程用你的物理母语(点过程、临界、分形、标度极限)讲通。**这种"打通尺度"的解释,是理解胜于拟合的最高形式。**

但也要谦卑:涌现的解释**强在机制、弱在精确**。我们能说"长记忆自激→粗糙",却还不能完全说清"为什么订单流恰好这么自激、这么长记忆"——**每解释一层,新的"为什么"又冒出来**。这与全项目一致:[模型/解释是更好的地图,永远不是疆域](../../../docs/12-总复习知识地图.md)。**但每往下打通一层,你对市场的理解就更深一分。**

## 七、动手

跑 `python hawkes_to_rough.py`,然后:

1. **调 γ**:把 `gamma0` 从 0.7 改到 0.4(尾更重)和 0.95(尾更轻),看活动度变多粗糙、H 怎么动。
2. **调临界度**:把 `n_branch` 从 0.9 改到 0.99(更临界)和 0.5,看事件成簇和活动度的变化(注意:有限样本里 n 对 H 的作用较微妙)。
3. **接 ④**:把这里 Hawkes 生成的活动度,喂给 [④](../04-粗糙波动率/笔记.md) 的 ζ_q 单分形分析,看是不是也呈 ζ_q=qH 的直线。
4. **接 ⑤**:用 Hawkes 活动度当方差,驱动一条价格路径,反解隐含波动率,看 [⑤](../05-粗糙波动率定价rBergomi/笔记.md) 的陡短偏斜是否复现——把整条链跑通。

## 八、本课小结（费曼版）

- **rough vol 的微观起源**:粗糙波动率源自**自激 + 长记忆**的订单流。③ 的近临界 Hawkes(n≈0.9)+ 幂律核(长记忆),聚合出的活动度**天然粗糙**。
- **Jaisson-Rosenbaum**:严格证明近临界 + 长记忆 Hawkes → rough Heston(标度极限)。把 ④ 的"假设"变成"推导"。
- **模拟看见**:幂律 Hawkes 活动度 Hurst **H≈0.12**,落在实证 ④ 的 H≈0.1 范围;γ(尾指数)调粗糙度,尾越重越粗糙。
- **物理**:**涌现**——微观自激 + 临界 + 长记忆 → 宏观标度不变的粗糙(分形);你的统计物理直觉是母语。
- **大闭环**:微观订单流(③)→ 宏观粗糙波动率(④)→ 期权微笑(⑤),整条尺度链打通。
- **诚实**:机制定性演示稳健,精确普适 H 需严格标度论证;每解释一层,新"为什么"又起。
