# C2 · CAPM 与 Beta

> 承接 C1 的"两基金分离"：如果人人都持有同一个市场组合，会推出什么定价关系？
> 答案是金融最有名的模型 **CAPM**，以及那个你常听到的词——**Beta**。配套代码：[`capm_beta.py`](capm_beta.py)。

> 🧭 按[「讲透」模板](../../../docs/06-深入学习大纲.md)：本质 → 推导 → 思维模型 → 哲学 → 闭环。

---

## 一、本质（一句话）

> **均衡状态下，一只资产该有多少预期收益，只取决于它对"整个市场"的敏感度（Beta），与它自己的特异波动无关。** 因为特异风险能被免费分散掉，市场不为"可以免费消除的风险"付钱。

一句更狠的话：**你只因为承担"躲不掉的风险"而获得回报。能躲掉的风险（特异风险），承担它你一分钱补偿都拿不到。**

---

## 二、从 C1 推出市场组合

C1 的两基金分离说：人人都持有"无风险资产 + 同一个切点组合"。现在做一步均衡推理：

> 如果**所有人**持有的风险部分都是同一个组合，那把所有人的持仓**加总**起来，得到的就是**整个市场**。所以那个人人都持有的"切点组合"，必然就是**市场组合**（按市值加权的全体资产）。

于是市场组合 = 最优风险组合。这一步把"个人最优"变成了"市场均衡"，CAPM 就此诞生。

---

## 三、CAPM 公式与 Beta

**CAPM**：任何资产的预期超额收益，等于它的 Beta 乘以市场的风险溢价：

$$\boxed{\;\mathbb{E}[R_i] - r_f = \beta_i\,\big(\mathbb{E}[R_m] - r_f\big)\;}, \qquad \beta_i = \frac{\mathrm{Cov}(R_i, R_m)}{\mathrm{Var}(R_m)}$$

**Beta 是什么**（代码实验①）：把资产收益对市场收益做回归，那条直线的**斜率**就是 Beta——它度量"市场动 1%，这只资产平均动多少"：

- **β > 1**（进攻型）：放大市场波动（市场涨 1%，它涨 1.5%）。
- **β < 1**（防守型）：比市场温和。
- **β = 0**：和市场无关（理论上预期收益 = 无风险利率）。

> 🔗 闭环[线性代数课](../../../基础/数学/线性代数-组合与协方差的几何/)：Beta 用到协方差 $\mathrm{Cov}(R_i,R_m)$，本质是"资产收益向量在市场收益向量上的投影"。Beta 就是回归斜率。

**证券市场线（SML）**（代码实验②）：把 CAPM 画出来，就是"预期超额收益 ∝ Beta"的一条直线。所有资产理论上都该落在这条线上。

---

## 四、核心洞见：系统性 vs 特异风险

这是 CAPM 最深刻、最该记住的地方。任何资产的总风险，可拆成两块：

$$\text{总风险} = \underbrace{\text{系统性风险}}_{\beta\cdot\text{市场，躲不掉}} + \underbrace{\text{特异风险}}_{\text{自己的，可分散掉}}$$

代码实验③把它做实了：把越来越多股票放进组合，**特异风险被一只只地平掉**，组合波动一路下降，但**降到"市场风险"这个地板就停住了**（你没法把整个市场的涨跌分散掉）。

> 🔑 **CAPM 的灵魂**：既然特异风险**能被免费分散掉**，那承担它就**不该**有任何额外回报（否则就有套利——白拿补偿却不担真风险）。所以**只有系统性风险（Beta）被定价**。这把"一只资产值多少预期收益"这个难题，归结到了一个数：Beta。

---

## 五、Alpha：Beta 解释不了的部分

如果 CAPM 完美，所有资产都在 SML 上。现实里有偏离——这个**偏离**就是 **Alpha**（回归的截距）：

$$R_i - r_f = \alpha_i + \beta_i(R_m - r_f) + \varepsilon_i$$

- **Alpha = "Beta 解释不了的超额收益"** = 真本事（选股能力）、或定价错误、或……**运气**。
- 整个主动管理行业都在追求正 Alpha，但**扣费后，大多数基金的 Alpha ≈ 0 甚至为负**（呼应[有效市场假说](../../../docs/03-哲学与历史背景.md)）。

代码实验④给了一记警钟：40 只**真实 Alpha = 0** 的基金，纯靠运气，估出来的 Alpha 却散布在 **−20% 到 +10%** 之间！真有 5%、8% 本事的，也淹没在噪声里。

> 🔗 闭环[概率课](../../../基础/数学/概率统计-区分信号与噪声/)：区分"真 Alpha"和"运气"是个假设检验问题，而且**需要很多年数据**（还记得 $t\approx \text{夏普}\times\sqrt{\text{年数}}$ 吗？）。**看到一只基金"跑赢大盘"，先默认它是 Beta + 运气，而非 Alpha。**

---

## 六、思维模型

1. **只有躲不掉的风险被定价**：能分散的风险无补偿。这是配置与定价的第一原则——别为可消除的风险要价，也别指望它给你回报。
2. **Beta = 系统性敞口**：用一个数概括"你对大盘的暴露"。管理组合，先管 Beta。
3. **Alpha = 真本事（且极难证明）**：把"跑赢"分解成"承担 Beta（不算本事）"+"Alpha（才算本事）"，再用统计去拷问 Alpha 是不是运气。
4. **市场是基准**：CAPM 把市场组合立成了标尺。任何策略都先问"它的 Beta 和 Alpha 各是多少"。

---

## 七、哲学指导与局限：又一个"美丽但不准"的模型

CAPM 优雅、影响深远（Beta、Alpha、系统性风险这些词都来自它），但**实证上站不太住**：

- **低 Beta 异象**：现实中低 Beta 股票的回报，**高于** CAPM 的预测（SML 实际比理论平）。
- **规模、价值效应**：小盘股、低估值股的回报，CAPM 解释不了 → 催生了**多因子模型**（Fama-French，下一课 C3）。
- **假设不现实**：人人均值-方差优化、能以无风险利率借贷、对未来看法一致……都太理想。
- **市场组合不可观测**：真正的"全市场"（含房产、人力资本……）根本测不准。

> 但和 [Black-Scholes](../../路线B-衍生品定价/03-BlackScholes公式/) 一样，CAPM 是"**错但不可或缺**"的：它提供了**Beta / Alpha / 系统性风险**这套人人都用的语言和思维框架。**懂它、用它的概念，但别把那条 SML 当成铁律。** 它的失败之处（多因子），正是 C3 的起点。

## 八、动手

跑 `python capm_beta.py`，然后：

1. **估 Beta**：给实验①再加一只 β=1.0、idio_vol 很大的股票，看它的点云多散、但回归斜率仍≈1。体会"高特异风险不改变 Beta"。
2. **分散地板**：把实验③的 `idio_vol` 调大，初始风险更高，但最终仍收敛到同一个市场地板——地板由系统性风险决定，与特异风险无关。
3. **Alpha 打假**：把实验④的样本天数从 2000 改成 10000（约 40 年），看零-Alpha 基金的估计散布是否收窄（√年数 的力量）。

## 九、本课小结（费曼版）

- **CAPM**：均衡下 $\mathbb{E}[R_i]-r_f = \beta_i(\mathbb{E}[R_m]-r_f)$；预期收益只由 **Beta** 决定。
- **Beta** = 资产对市场回归的斜率 = 系统性风险（躲不掉）。
- **核心洞见**：特异风险能免费分散掉 → 不被定价 → **只有系统性风险有回报**。
- **Alpha** = Beta 解释不了的超额 = 真本事 or 运气；**极难和运气区分**（要很多年数据）。
- **局限**：低Beta异象、规模/价值效应 → CAPM 不够，需多因子（C3）；但 Beta/Alpha 是通用语言。

## 十、思考题

1. 一只股票特异波动极大（自己上蹿下跳），但 Beta=0（和大盘无关）。CAPM 说它的预期超额收益是多少？为什么"它自己很波动"不该给你额外回报？
2. 某基金连续 5 年跑赢大盘 3%。在你欢呼"找到股神"之前，用 C2（Beta + Alpha）和[概率课](../../../基础/数学/概率统计-区分信号与噪声/)（运气 vs 本事）各提一个该追问的问题。
3. 如果"低 Beta 股票回报高于 CAPM 预测"是真的，你能设计一个利用它的策略吗？（提示：买低 Beta、适当加杠杆——这就是著名的"低波动异象"策略；但想想它的风险在哪）
