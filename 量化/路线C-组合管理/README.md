# 路线 C · 组合管理 📊

> 路线 A（择时选股）赌的是"预测对方向"；路线 C 走的是另一条路：**不预测涨跌，而是科学地配置与分散**。
> 这是更稳健、更适合长期的视角，也是你的[线性代数 wᵀΣw](../../基础/数学/线性代数-组合与协方差的几何/) 和[最优化](../../基础/数学/微积分与最优化-复利泰勒与找最优/)地基的主战场。

---

## 核心问题

> 给定一堆资产，**钱该怎么分**，才能在"风险-收益"上做到最好？

从马科维茨 1952 年的答案（有效前沿）出发，一路到 CAPM、因子模型、风险平价——以及一个贯穿始终的清醒认识：**这套理论很美，但对输入（尤其是预期收益）极其敏感、实务中很脆弱。**

## 一条主线

**马科维茨(分散的数学) → 有效前沿 → 加无风险资产得切点组合(最大夏普) → CAPM(Beta) → 因子模型 → 风险平价；全程警惕：优化是放大器，输入有噪声。**
