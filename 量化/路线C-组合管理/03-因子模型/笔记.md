# C3 · 因子模型

> CAPM 用"一个因子（市场）"解释收益，但现实需要**多个因子**。因子模型是现代量化选股、
> 业绩归因、风险管理的基石，也是连接[线性代数 PCA](../../../基础/数学/线性代数-组合与协方差的几何/) 的地方。配套代码：[`factor_models.py`](factor_models.py)。

> 🧭 按[「讲透」模板](../../../docs/06-深入学习大纲.md)：本质 → 推导 → 思维模型 → 哲学 → 闭环。

---

## 一、本质（一句话）

> **一只资产的收益，可以拆成"对若干共同风格因子（市场、规模、价值……）的暴露" + "它自己的特异部分"。** CAPM 只是"只有市场一个因子"的特例。

观念升级：收益不是铁板一块，而是**几种"风格收益"的配方**。理解一个组合，就是看清它**对各因子暴露多少**（它的"DNA"）。

---

## 二、从 CAPM 到多因子

CAPM 说预期收益只由市场 Beta 决定。但实证发现它**解释不了**几个顽固现象（C2 末尾提过）：小盘股、低估值（价值）股的长期回报，比 CAPM 预测的高。

Fama 和 French（1992）的解法：**再加两个因子**。

$$R_i - r_f = \alpha + \beta_{\text{mkt}} \text{MKT} + \beta_{\text{smb}} \text{SMB} + \beta_{\text{hml}} \text{HML} + \varepsilon$$

- **MKT**：市场因子（就是 CAPM 那个）。
- **SMB**（Small Minus Big）：小盘 − 大盘的收益差 = "规模因子"。
- **HML**（High Minus Low）：高账面市值比（价值股）− 低（成长股）= "价值因子"。

后来还有**五因子**（加盈利 RMW、投资 CMA）、**动量**（Momentum）、质量、低波动……每个因子都是一种"被历史数据支持的风格溢价"。

---

## 三、因子模型能做什么

### 1. 解释力更强，揪出"假 Alpha"（代码实验①）
一只**真实 Alpha = 0** 的价值股，用 CAPM（单因子）回归，会冒出一个**虚假的 +7.9% "Alpha"**——因为 CAPM 看不见"价值"这个因子，就把价值溢价误记成了"本事"。换上 3 因子，R² 从 0.74 升到 0.93，**那个假 Alpha 立刻塌到 0.3%**。真相大白：**它没有本事，只是吃了价值因子的红利。**

> 🔑 这是因子模型最重要的用途：**把"看起来的 Alpha"分解，看它到底是真本事，还是只是某种可廉价复制的因子暴露。** 它大大**提高了"真 Alpha"的认定门槛**。

### 2. 看穿风格 DNA（代码实验②）
不同基金的因子载荷一目了然：价值基金 HML 载荷高，成长基金 HML 为负，小盘基金 SMB 高。**因子载荷就是基金的 DNA**，告诉你它在赌什么风格。

### 3. 业绩归因（代码实验④）
把一个组合的总收益**拆成各来源的贡献**：市场赚了多少、规模赚了多少、价值赚了多少、真 Alpha 多少。代码例子里 9.3% 的总收益，6% 来自市场、1.5% 来自价值，**真 Alpha 只有 1.2%**。这让你诚实地回答："这个'跑赢'，到底是本事还是风格红利？"

> 🔗 闭环[线性代数 PCA](../../../基础/数学/线性代数-组合与协方差的几何/)：因子可以是"基本面定义的"（SMB/HML），也可以是"统计提取的"（对协方差矩阵做 PCA，最大主成分≈市场因子）。因子模型本质上就是给收益矩阵做**低维分解**。

## 四、思维模型

1. **收益 = 因子暴露的配方**：分析任何资产/组合，先问"它对哪些因子暴露多少"，而非孤立看它。
2. **提高 Alpha 的门槛**：控制了越多已知因子，"剩下的 Alpha"才越可能是真本事。"跑赢"先归因到因子，剩下的才配叫技能。
3. **风格即风险敞口**：因子暴露既是收益来源，也是风险来源（价值因子也会连跌好几年）。管理组合 = 管理因子敞口。
4. **降维**：几个因子解释一大堆资产的共同波动——把高维问题压缩成低维，和 PCA 同源。

---

## 五、哲学指导与局限：当心"因子动物园"🦓

因子模型威力大，但通往一个**触目惊心的陷阱**——**因子动物园（factor zoo）**：

> 学术界和业界已经"发现"了**数百个**号称能预测收益的因子。但 López de Prado 等人指出：**其中绝大多数是数据挖出来的噪声。**

代码实验③演示了为什么：测 300 个**纯随机**的"假因子"，仍有 **18 个（≈5%）碰巧 |t|>1.96 显著**。

> 🔗 这正是[第 05 课的"数据窥探/多重检验"](../../../量化/第05课-给策略祛魅/)、[概率课的"多重检验陷阱"](../../../基础/数学/概率统计-区分信号与噪声/)在因子研究里的翻版：**试的因子越多，撞出"显著但虚假"的因子就越多。** 一篇篇论文发表着这些幸运儿，大多在样本外失效。

其他局限：
- **因子拥挤与衰减**：一个因子被发现、被大量资金涌入后，溢价会被磨平甚至反转（[适应性市场](../../../docs/03-哲学与历史背景.md)）。
- **"风险溢价"还是"异象"？**：价值因子的超额，是因为它承担了某种真实风险（该有补偿），还是市场的系统性错误（迟早消失）？这是个**没有定论的哲学争论**，决定了你该不该相信它会持续。

> 落点：因子模型是强大的**归因与理解工具**，但**别把"发现一个新因子"太当回事**——先用第 05 课的诚实清单拷问它：样本外成立吗？经得起多重检验校正吗？有经济逻辑吗，还是纯挖数据？

## 七、本课小结（费曼版）

- **因子模型**：收益 = 多个共同因子暴露 + 特异；**CAPM 是单因子特例**。
- **Fama-French**：市场 MKT + 规模 SMB + 价值 HML（+ 盈利、投资、动量……）。
- **三大用途**：揪出假 Alpha（看起来的本事多是因子暴露）、看穿风格 DNA、业绩归因。
- **降维**：与[PCA](../../../基础/数学/线性代数-组合与协方差的几何/)同源；统计因子 = 主成分。
- **大坑**：**因子动物园**——数百个因子大多是多重检验挖出的噪声（呼应第 05 课）。先拷问再相信。

## 八、思考题

1. 一只基金过去 5 年年化跑赢大盘 4%。用因子模型，你会怎样判断这 4% 是"真本事"还是"价值/小盘风格红利"？（提示：拿它的收益对 FF 因子回归，看 Alpha 还剩多少）
2. 为什么"控制的因子越多，认定真 Alpha 就越难"？这对主动基金经理是好消息还是坏消息？
3. 价值因子连续跑输了十年（如 2010s）。这是"价值因子死了"，还是"风险溢价本就会有长期回撤"？你怎么用数据和逻辑去判断？（这关乎"风险溢价 vs 异象"的根本争论）
