# 路线 E · 数学物理深化（econophysics）🔬

> **压轴之作，为你的物理背景量身定做。** 前面 B5 让你看到 Black-Scholes = 热方程（正常扩散）；
> 这条线把那个"正常"的假设打碎，用**统计物理**的眼睛重看市场：厚尾、幂律、反常扩散、相变、分形。
> 这是"数学物理"和"量化"在本项目里的最终合流。

---

## 核心叙事：从"正常"到"反常"

```
随机过程(布朗运动,正态) → B5(BS=热方程,正常扩散) ← 美丽但是错的
                ↓ econophysics 的修正
真实市场:厚尾·幂律·反常扩散·相变·分形 ← 狂野但是真的
```

主流金融建立在**高斯/布朗运动**之上（[随机过程课](../../基础/数学/随机过程-从抛硬币到布朗运动/)、[B5](../路线B-衍生品定价/05-BS与热方程的同构/)）。但物理学家（Mandelbrot、Stanley、Bouchaud、Sornette）发现：**真实市场根本不是高斯的**。它的极端事件、它的崩盘、它的自相似结构，更像物理里的**临界现象、反常扩散、湍流**。

## 为什么这是你的主场

这条线用到的每一样——幂律、临界指数、标度律、分形、反常扩散、Ising 模型、配分函数——**你在物理里都见过**。你不是在学新东西，而是在**把熟悉的物理迁移到市场**。许多物理博士正是这样进入量化前沿的（[哲学与历史课](../../docs/03-哲学与历史背景.md)）。
