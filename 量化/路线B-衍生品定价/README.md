# 路线 B · 衍生品定价 📐🔬

> 这条线是为**有数学物理背景的你**准备的高潮。它回答一个深刻的问题：
> **在"无法预测涨跌"（时间序列那课的结论）的前提下，人类凭什么能给期权精确定价？**
> 答案是一个绝美的思想：**不靠预测，靠"无套利"和"复制"。** 终点是 Black-Scholes 公式，以及它与你熟悉的**热传导方程**的同构。

---

## 为什么这条线适合你

你已经备齐了全部弹药（数学地基五块）：
- **随机过程**（布朗运动、伊藤引理）→ 描述股价怎么随机演化
- **微积分与最优化**（泰勒、偏导）→ 希腊字母、PDE
- **概率统计**（期望、分布）→ 风险中性期望

衍生品定价把它们全用上，并最终通向**物理**：Black-Scholes 方程换元后**就是热方程**。爱因斯坦的扩散、Bachelier 的期权、你《数学物理方法》里的热传导，在这里合三为一。
