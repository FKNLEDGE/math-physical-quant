# B3 · Black-Scholes 公式

> 路线 B 皇冠上的明珠。B2 的二叉树取极限（N→∞）就得到这个 1973 年的传奇公式——
> 它让期权定价从"算"变成"查公式"，开启了万亿美元的衍生品市场，并为作者赢得诺奖。
> 配套代码：[`black_scholes.py`](black_scholes.py)。

> 🧭 按[「讲透」模板](../../../docs/06-深入学习大纲.md)：本质 → 公式 → 含义 → 希腊字母 → 哲学 → 闭环。

---

## 一、本质（一句话）

> **Black-Scholes = 在"股价服从几何布朗运动、可连续无成本对冲"的理想世界里，欧式期权无套利价格的闭式公式。** 它就是 B2 二叉树在"步数→∞"极限下的解析答案。

---

## 二、公式本身

欧式**看涨**期权（行权价 K、到期 T、无风险利率 r、波动率 σ）：

$$\boxed{C = S_0\,N(d_1) - K e^{-rT} N(d_2)}$$
$$d_1 = \frac{\ln(S_0/K) + (r + \tfrac12\sigma^2)T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}$$

其中 $N(\cdot)$ 是标准正态的累积分布（"小于某值的概率"）。代码验证：$S_0=K=100, r=5\%, \sigma=20\%, T=1$ 时 $C=10.45$——**正是 B2 二叉树收敛到的那个数，也满足 B1 的看跌看涨平价**（$P=5.57$）。三课的答案完全自洽。

> 看跌用平价或对称公式：$P = Ke^{-rT}N(-d_2) - S_0 N(-d_1)$。

---

## 三、公式在说什么（别被 d₁ d₂ 吓到）

把公式拆成两块，每块都有清晰的金融含义：

$$C = \underbrace{S_0 N(d_1)}_{\text{“到期能拿到股票”的现值}} - \underbrace{K e^{-rT} N(d_2)}_{\text{“到期要付出 K”的现值}}$$

- **$N(d_2)$ = 风险中性世界里，期权到期"实值"（$S_T > K$，值得行权）的概率。** 代码里 = 0.56。这直接呼应 B2 的风险中性定价：期权价 ≈ 折现的"行权概率 × 收益"。
- **$N(d_1)$ = 期权的 Delta**（$\partial C/\partial S$，代码里 = 0.637）。它既是对冲比率（B2 的 Δ！），也用于计算"行权时股票的期望现值"。
- 两项相减 = "（按概率）我能得到的股票现值" − "（按概率）我要付的行权款现值" = 期权净值。

> 💡 你不必会推导那个积分，但要记住这个"**概率加权的得失**"结构。$d_1, d_2$ 只是把 $S_0, K, r, \sigma, T$ 打包进正态分布的两个"标准化距离"。

### 它从哪来（两条推导路线，了解即可）
1. **风险中性期望路线**（B2 的延续）：$C = e^{-rT}\,\mathbb{E}_q[\max(S_T-K,0)]$，其中 $S_T$ 在风险中性世界里服从**对数正态**（因为股价是几何布朗运动——[随机过程那课](../../../基础/数学/随机过程-从抛硬币到布朗运动/)）。把这个期望的积分算出来，就是上面的公式。
2. **对冲/PDE 路线**：构造"期权 − Δ 股股票"的无风险组合，要求它只赚无风险利率，用[伊藤引理](../../../基础/数学/随机过程-从抛硬币到布朗运动/)推出 **Black-Scholes 偏微分方程**，再解它。**这条路线的终点，就是 B5——那个 PDE 换元后竟是热方程。**

## 四、五个希腊字母：期权的"风险仪表盘"

希腊字母 = 期权价对各因素的**敏感度** = **各种导数**（闭环[微积分那课](../../../基础/数学/微积分与最优化-复利泰勒与找最优/)"导数=敏感度"）。它们是做市商每天盯的仪表盘：

| 希腊字母 | 是什么导数 | 直觉 | 图形特征 |
|---|---|---|---|
| **Delta** $\partial C/\partial S$ | 对股价（一阶） | 股票动 1，期权动多少；也是对冲比率 | S 形，从 0 升到 1 |
| **Gamma** $\partial^2 C/\partial S^2$ | 对股价（二阶） | Delta 变多快；曲率/对冲难度 | 平值处最高（钟形） |
| **Vega** $\partial C/\partial\sigma$ | 对波动率 | 波动率涨 1%，期权涨多少 | 平值处最高 |
| **Theta** $\partial C/\partial t$ | 对时间 | 时间流逝，期权每天掉多少价（时间价值衰减） | 通常为负 |
| **Rho** $\partial C/\partial r$ | 对利率 | 利率变动的影响 | 通常较小 |

代码图②③把它们画了出来。两个要点：

- **Gamma 与 Theta 是一对冤家**：买期权的人有正 Gamma（曲率有利，大波动赚钱）但付负 Theta（每天流血等待）。这正是 [Taleb 凸性](../../../docs/03-哲学与历史背景.md)的代价——**你为"大波动时获利"的权利，每天交一点"租金"**。
- **泰勒展开的回声**：$\Delta C \approx \text{Delta}\cdot\Delta S + \tfrac12\text{Gamma}\cdot\Delta S^2 + \text{Theta}\cdot\Delta t$。一阶 Delta、二阶 Gamma、时间 Theta——正是[微积分课](../../../基础/数学/微积分与最优化-复利泰勒与找最优/)泰勒展开在风险管理里的化身。

## 五、隐含波动率与"微笑"：市场亲口告诉你 BS 错在哪

公式里 $S_0, K, r, T$ 都能直接观测，只有 **σ（波动率）看不见**。于是市场反过来用：**给定市场上的期权价格，反解出让 BS 公式吻合的那个 σ**——叫**隐含波动率（implied volatility）**。它是"市场对未来波动的预期"，也是著名的**恐慌指数 VIX** 的基础。

**关键观察**：如果世界真的是"常波动率的 BS 世界"，那么不同行权价反解出的隐含波动率应该**都一样（一条平线）**。但现实里（代码图④）：

> 隐含波动率呈 **U 形"微笑"**——平值最低，两侧行权价都更高。股市里更常见**左高右低的"偏斜"**（深度虚值看跌特别贵，因为大家怕暴跌）。

**这意味着什么？** 真实收益**厚尾**（大涨大跌都比正态多，呼应 [Mandelbrot](../../../docs/03-哲学与历史背景.md) 和[时间序列课](../../../基础/数学/时间序列-价格的记忆与平稳性/)），而 BS 假设的对数正态低估了尾部。于是市场给两翼的期权"加价"，反解出来就是更高的隐含波动率。**这条微笑曲线，是市场用真金白银亲口承认："BS 的常波动率假设是错的。"** 1987 股灾后，这条偏斜变得尤为陡峭。

---

## 六、思维模型

1. **闭式公式 vs 数值**：能写成公式（BS）就秒算且能求导（希腊字母）；写不出就靠数值（二叉树/蒙特卡洛，B4）。两手都要有。
2. **希腊字母 = 风险仪表盘**：不要只看价格，要看它对各因素的敏感度。专业玩家管理的是 Delta/Gamma/Vega，而非价格本身。
3. **隐含波动率 = 市场的"恐惧计价"**：它把"价格"翻译成"市场对未来动荡的预期"，比价格本身信息量大得多。
4. **微笑 = 模型与现实的差**：当一个本该是常数的参数变成了曲线，就是模型在告诉你它的假设破了。**会读"模型的残差"，是高手标志。**

---

## 七、哲学指导与局限：史上最成功的"错误模型"

Black-Scholes 几乎每条假设都是错的：波动率不恒定（有微笑）、收益非对数正态（厚尾）、不能连续无成本对冲、价格会跳空。**然而它依然是金融史上最有用的公式。** 为什么？

> 因为它提供了一套**所有人共享的语言**。即便大家都知道它"错"，市场仍用它来**报价、换算、沟通**——把所有"错"统一打包进一个看得见、可交易的量：**隐含波动率**。BS 没有消灭复杂性，而是把复杂性**搬运**到了一个大家都盯着的地方（波动率曲面）。

这是[「所有模型都是错的，但有些有用」](../../../docs/02-方法论与思维模型.md)的终极范例。教训有二：
- **别把 BS 当真理**：它的常波动率假设在危机时刻（波动率暴涨、相关性冲 1、跳空）会致命地低估风险——1987、1998、2008 反复上演。
- **但要懂 BS 的语言**：因为整个市场用它沟通。不懂隐含波动率，就听不懂期权市场在说什么。

## 八、动手

跑 `python black_scholes.py`，然后：

1. **验证三课自洽**：用代码确认 $C - P = S_0 - Ke^{-rT}$（B1 平价），且 $C$ 与 B2 大 N 二叉树一致。
2. **玩希腊字母**：把 σ 从 20% 调到 40%，看 Vega 处期权价涨多少、Gamma 形状怎么变。
3. **隐含波动率**：用 `implied_vol` 反解：先用 σ=30% 算一个价，再把这个价喂回去，确认反解出 30%。
4. **挑战**：把图④的波动率混合改成"带负向暴跌"，看能不能造出股市那种**左高右低的偏斜**（而非对称微笑）。

## 九、本课小结（费曼版）

- **Black-Scholes** = 二叉树 N→∞ 的闭式解：$C = S_0N(d_1) - Ke^{-rT}N(d_2)$。
- **含义**：$N(d_2)$=风险中性实值概率，$N(d_1)$=Delta；公式 = 概率加权的"得到股票 − 付出 K"。
- **五个希腊字母** = 各种导数 = 风险仪表盘；Gamma 与 Theta 是凸性的"收益与租金"。
- **隐含波动率**：从价格反解的 σ；本应是平线，实际呈**微笑/偏斜** → 证明真实市场厚尾、BS 假设破了。
- **哲学**：BS 是"史上最成功的错误模型"——大家共享的语言，把复杂性搬到隐含波动率上；懂它、用它，但别信它在尾部。
