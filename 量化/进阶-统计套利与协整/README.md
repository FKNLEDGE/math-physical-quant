# 进阶 · 统计套利与协整 📈

> **进阶路线之一。** 主线说"方向难测"——统计套利给出一条出路：**不赌方向，赌价差回归**。
> 这是一整类**真实可部署**的经典量化策略，数学清晰、用得上你的随机过程底子。

## 核心思想

```
方向不可测(时间序列课) → 但'绑在一起'的资产,其价差均值回归(协整)
   → 检验协整 → 量回归速度(OU半衰期) → z-score入场出场 → 市场中性
```
