# 中国市场特殊性（A股规则与坑）

> 本项目大量例子用的是"美股范式"。但你大概率在 A 股练手——**A 股有一套独特规则，直接决定策略可不可行。**
> 把美股策略原样搬过来，常常水土不服。这一课讲清 A 股的关键规则与坑。配套代码：[`a_share_rules.py`](a_share_rules.py)。

> 🧭 按[「讲透」模板](../../docs/06-深入学习大纲.md)：本质 → 六大规则 → 影响 → 机会 → 闭环。

---

## 一、本质（一句话）

> **回测必须编码市场的真实规则，否则它在对你撒谎。** A 股的 T+1、涨跌停、印花税、做空限制、停牌……每一条都会让"理想回测"和"真实能赚到的"产生巨大鸿沟。

代码实验①直接量化了这个鸿沟：同一个均线策略，**理想回测 56.3% / 夏普 0.60，加上 A 股的 T+1 和真实成本后只剩 45.0% / 0.50**——摩擦吃掉了 11 个点。而这还没算涨跌停、停牌的影响。

---

## 二、六大关键规则

### 1. T+1（当天买，不能当天卖）
A 股股票**今天买入，最早明天才能卖**（债券、ETF 部分 T+0）。
- **影响**：纯日内、高频"低买高卖同一只"的玩法在 A 股股票上**做不了**；你的反应天然慢一拍。
- 代码里用"再延迟一天"近似它，已能看到收益被磨低。

### 2. 涨跌停（价格限制）
A 股有每日**价格涨跌幅限制**：

| 板块 | 涨跌停幅度 |
|---|---|
| 主板（沪深） | **±10%** |
| ST 股 | **±5%** |
| 创业板 / 科创板 | **±20%** |
| 北交所 | ±30% |

- **最大的坑**：**封板（封死涨停/跌停）时，往往根本买不到或卖不掉**——挂涨停价买，前面排着几亿手，成交不了。
- **回测陷阱**：若你的回测假设"涨停时也能买入/跌停时也能卖出"，是**严重高估**。必须过滤掉涨跌停无法成交的情形。代码图④画出了限制线。
- **衍生现象**：**一字板**（开盘即封死，全天没有成交机会）、**连板**（连续涨停）——A 股特有的"打板"文化由此而来。

### 3. 交易成本（佣金 + 印花税 + 过户费）
A 股一次"买入再卖出"的往返成本，约 **10~13 个基点**（代码图③拆解）：

| 项目 | 大致费率 | 备注 |
|---|---|---|
| 佣金 | 约 0.01%~0.03%（双边，最低 5 元） | 券商收，可谈 |
| **印花税** | **0.05%（仅卖出，2023 年起）** | 国家收，**单边**，是大头 |
| 过户费 | 约 0.001%（双边） | 沪市为主 |

- **关键**：印花税**只在卖出时收**，所以卖出成本 > 买入成本（代码里做了买卖不对称）。
- **影响**：换手越勤，成本吃得越狠。**A 股高换手策略尤其难做**（呼应[第 05 课](../第05课-给策略祛魅/)）。

### 4. 散户做空难
- 散户**不能直接裸卖空**股票。要做空只能通过**融资融券**（借券卖出），但 A 股**可融券的标的池小、券源紧张、有成本**，且常常"无券可融"。
- 还有**股指期货、ETF 期权**等对冲工具，但门槛/成本较高。
- **影响**：A 股策略**默认是"只做多/空仓"**（long-only），像[第 04 课](../第04课-第一个策略-均线交叉/)那样。纯多空对冲、市场中性策略，散户很难落地。

### 5. 停牌 / 复牌
- A 股股票可能**长期停牌**（重大重组、核查等），把你的仓位**锁死**数周甚至数月，期间无法买卖。
- **数据坑**：停牌期数据有缺口；**复牌常跳空**（一次性补涨补跌），回测若不处理会失真。
- **影响**：流动性风险、无法及时止损。研究时要注意停牌股的处理。

### 6. 交易时间与集合竞价
- 连续竞价：**9:30–11:30、13:00–15:00**。
- **集合竞价**：开盘前（9:15–9:25）和收盘前（14:57–15:00）撮合成交，是重要的下单时点。
- 与美股的盘前盘后、做市商机制不同。

## 三、对策略的影响（小白必知）

| 规则 | 对你的策略意味着 |
|---|---|
| T+1 | 别做需要日内反复进出的策略 |
| 涨跌停 | 回测必须剔除涨跌停无法成交；"打板"策略受封板动态主宰，极难回测真实 |
| 成本（印花税卖出） | 控制换手；高频/高换手在 A 股几乎必死 |
| 做空难 | 默认 long-only；市场中性/纯空头策略散户难做 |
| 停牌 | 流动性风险，数据要处理缺口与复牌跳空 |
| 散户主导 | A 股散户占比高，情绪化、动量/题材特征更强，微观结构与美股不同 |

## 四、规则也是机会（但都很拥挤、很危险）

A 股的规则不只是约束，也催生了一些**本土特色策略**——但务必带着[第 05 课的诚实](../第05课-给策略祛魅/)和[A+1 的仓位纪律](../路线A+实战进阶/01-仓位管理与资金管理/)看待，它们大多**极度拥挤、风险极高**：

- **打板 / 涨停板战法**：博弈连板动量（高风险，被游资主导）。
- **次新股、题材轮动**：A 股题材炒作活跃。
- **北向资金（陆股通）**：跟踪外资流向。
- **指数增强、可转债**：相对稳健的量化方向。

> ⚠️ 别一上来就冲"打板"这种高风险博弈。先用本项目的严谨流程，在 long-only、低换手、控制风险的框架里练扎实。

## 五、实操：数据与平台

- **平台**：聚宽 JoinQuant、掘金量化——它们的回测引擎**内置了 A 股的 T+1、涨跌停、成本、停牌**等规则，比你自己手写更真实。建议在上面跑，并和你本地的理解对照。

## 六、思维模型

1. **回测必须镜像真实规则**：每个市场都有自己的"物理定律"，回测不编码它们就是科幻小说。
2. **微观结构决定可行性**：同一个 idea，在能 T+0、能做空的市场可行，在 A 股可能根本做不了。
3. **规则=约束+机会**：限制催生摩擦，也催生只属于这个市场的模式——但后者通常更拥挤、更危险。
4. **先合规再优化**：先把"能不能真成交、扣完税费还剩多少"搞对，再谈优化收益。

## 七、本课小结（费曼版）

- **回测不编码 A 股规则 = 自欺**：同一策略,理想56%→A股现实45%(还没算涨跌停/停牌)。
- **六大规则**:①T+1(当天买不能卖)②涨跌停(±10/5/20%,封板买不到)③成本(印花税卖出单边,往返~13bp)④散户做空难(默认long-only)⑤停牌(锁仓+数据坑)⑥交易时间/集合竞价。
- **影响**:别做日内/高换手;默认只做多;控成本;处理停牌与复权。
- **机会**(高危):打板、题材、北向、指增/可转债——带着诚实与仓位纪律,别冲高危博弈。
- **实操**:数据用 AKShare;回测用聚宽/掘金(内置规则);务必用复权价。

## 八、思考题

1. 一个美股日内均值回归策略（同一天低买高卖），直接搬到 A 股股票会怎样？为什么？
2. 你的回测显示某"打板"策略年化 200%。基于本课和[第 05 课](../第05课-给策略祛魅/)，你要质疑哪几点？（提示：涨停能不能真买到、封板成交、幸存者偏差）
3. 印花税只在卖出收。这对"高换手"和"低换手"策略的相对优劣有什么影响？
