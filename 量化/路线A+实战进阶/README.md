# 路线 A+ · 实战进阶（主线与分支之间的桥）

> 主线 01–05 让你**看懂**量化、学会**怀疑**漂亮回测。但从"看懂"到"能独立做一个像样的小项目"，
> 还差一个**巩固期**。路线 A+ 就是这座桥：把所学串成肌肉记忆，补上小白必备的实操。

---

## 为什么需要它

很多人学完主线，一跳到[路线 B 衍生品定价](../路线B-衍生品定价/)就被劝退（无套利、伊藤引理太抽象）。问题不在你笨，而在**缺了"先用真实流程把简单策略做扎实"这一步**。A+ 专治这个断层。
