# 路线 D · 机器学习量化 🧠

> 机器学习是当今量化最热的方向，也是**翻车最多**的方向。这条线有两个目标：
> ①把 ML 的**第一性原理**讲清（监督学习、偏差-方差、交叉验证、树模型）；
> ②讲透**为什么金融是 ML 的"地狱"**——信噪比极低、非平稳、过拟合天堂，90% 的 ML 量化应用死在这。

---

## 为什么要带着"警惕"学

你已经有了最重要的两件防身武器：
- [第 05 课的"过拟合 / 数据窥探"](../第05课-给策略祛魅/) 和[概率课的"多重检验"](../../基础/数学/概率统计-区分信号与噪声/)——ML 把这些陷阱**放大了一百倍**。
- [微积分课的"梯度下降 + 优化是放大器"](../../基础/数学/微积分与最优化-复利泰勒与找最优/)——ML 模型就是这么训练的，也就是这么过拟合的。

> ⚠️ 这条线的核心态度：**ML 不是魔法，在金融里更不是。它是一把强大的"曲线拟合"刀，用好了切信号，用不好切到自己。** 先学会怀疑，再谈应用。
