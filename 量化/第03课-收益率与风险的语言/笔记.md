# 第 03 课 · 收益率与风险的语言

> 本课目标：把「价格」翻译成可比较的「收益率」，并用一套指标**同时**描述收益与风险。
> 这是量化的「普通话」——后面每节课都在说它。配套代码：[`lesson03_returns_risk.py`](lesson03_returns_risk.py)。

---

## 一、为什么不直接用价格

价格不能直接比较：A 股从 100→110，B 股从 10→11，**涨幅都是 10%**，但价差一个是 10、一个是 1。所以量化用**收益率**（涨跌百分比）说话，而不是价格本身。

> 农学类比：你比较两块田，不会比「总产量公斤数」（地块大小不同没法比），而是比**单产**（公斤/亩）这种归一化指标。收益率就是金融的「单产」。

---

## 二、两种收益率：简单 vs 对数

| | 公式 | 特点 |
|---|---|---|
| **简单收益率** | $r_t = \dfrac{P_t}{P_{t-1}} - 1$ | 直观（「涨了百分之几」），但**不可加** |
| **对数收益率** | $r_t = \ln\dfrac{P_t}{P_{t-1}}$ | 量化常用，**可加**、更接近正态 |

**为什么量化偏爱对数收益率？** 两个硬核理由（运行代码能亲眼看到）：

1. **可加性**：多天的对数收益**直接相加**就是总的对数收益。
   $$\ln\frac{P_n}{P_0} = \sum_{t=1}^{n} \ln\frac{P_t}{P_{t-1}}$$
   代码里验证了：把每天对数收益加起来还原 = 直接用首尾价格算 = **124.09%，完全一致**。简单收益率做不到（得连乘）。
2. **对称性 & 近正态**：+10% 再 -10%，简单收益率不回原点（亏 1%），对数收益率则对称。许多统计工具假设正态，对数收益率更配合。

> 🔬 这背后是连续复利 $P_t = P_0 e^{rt}$ 的性质——你在微积分里见过的 $e^x$。追到这一层就是[第一性原理](../../docs/02-方法论与思维模型.md)思维：不死记「要用 log」，而知道**为什么**。

## 三、五个必会指标（收益 × 风险）

新手只看「赚了多少」，高手**同时**看「冒了多大风险」。代码里把公式都摆在眼前：

| 指标 | 公式 / 算法 | 在说什么 |
|---|---|---|
| **年化收益率** | 日均收益 × 252 | 赚钱速度 |
| **年化波动率** | 日波动 × √252 | 颠簸程度（风险）。注意是 **√252** 不是 252 |
| **夏普比率** | (年化收益 − 无风险利率) / 年化波动 | **每单位风险换来多少收益**，>1 算不错。量化最核心的单一指标 |
| **最大回撤** | 从历史最高点跌下来的最大幅度 | 最痛的一次亏损，决定你「拿不拿得住」 |
| **胜率** | 上涨天数 / 总天数 | 赢的频率（但别只看它，要配合盈亏比） |

> **为什么波动率年化要乘 √252？** 方差随时间**线性**增长（独立增量相加，方差相加），标准差是方差的平方根，所以标准差随时间按 **√t** 增长。一天的波动 × √252 ≈ 一年的波动。这是随机游走的基本性质（也是布朗运动的性质，呼应[第 01 课](../第01课-量化是什么/)）。

**本课示例股（买入持有）的体检**：年化 13.46% / 波动 15.47% / 夏普 0.87 / 最大回撤 **-30.88%** / 胜率 51.8%。
夏普 0.87 还行，但**最大回撤 -31%**——意味着你得扛得住账户从高点缩水近三分之一。这就是为什么「只看收益率会骗人」。

## 四、两张必看的图

跑代码生成的 `第03课配图.png` 有三幅，前两幅是量化报告标配：

1. **净值曲线（Equity Curve）**：1 块钱本金的资产怎么长大。能看出牛市、熊市、修复的全过程。
2. **水下回撤图（Underwater Plot）**：任意时刻「距离前高跌了多少」。红色越深越久 = 越难熬。本图清楚显示 2020–2021 那段 -31% 的大坑。
3. **收益分布直方图**：钟形，但注意**两端的「厚尾」**——极端涨跌比正态分布预测的多。这正是 [Mandelbrot 对正态金融的批判](../../docs/03-哲学与历史背景.md)，也是风控不能只信正态的原因。

## 六、本课小结（费曼版）

- 价格不可比，用**收益率**；量化偏爱**对数收益率**，因为它**可加**且近正态。
- 永远**收益与风险一起看**：年化收益、年化波动、**夏普**、**最大回撤**、胜率。
- 波动率年化乘 **√252**（方差线性增长 → 标准差按 √t）。
- **净值曲线 + 水下回撤图**是量化报告的标配，收益分布有**厚尾**。

2. 为什么「+10% 再 -10% 不回本」？用对数收益率解释这个不对称（提示：复利的[凸性](../../docs/02-方法论与思维模型.md)）。
3. 收益分布的「厚尾」对风险管理意味着什么？如果你用正态分布估计「最坏一天能亏多少」，会高估还是低估风险？
